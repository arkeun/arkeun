## 처음 쓰는 사람에게 "한 판 더" 세 군데가 같은 뜻으로 읽히나

| 자리 | 문구 | 실제로 하는 일 |
|---|---|---|
| 저장 카드 | "할리갈리 한 판 더 적기" / "다른 게임 적기" | 같은 사람·같은 게임으로 시트 열기 / 같은 사람으로 시트만 열기 |
| 두 번째 저장부터 토스트 | "할리갈리 저장했어요 · **한 판 더** · 되돌리기" | 카드와 같음 |
| 홈 | "방금 한 할리갈리 · **한 판 더 적기** ›" | 카드와 같음 |
| 홈 초록 버튼 | "**오늘 기록에 더하기** · 오늘 적은 기록에 새 판을 더해요" | 사람만 채운 시트 |
| 초록 버튼 시트 안 | "할리갈리 한 판 더 · 방금 한 사람 그대로 N번째 판을 적어요" | 카드와 같음 |

- 셋(카드·토스트·홈 줄)은 같은 뜻으로 읽혀요. "한 판 더"라는 말이 같고, 앞에 게임 이름이 붙어서 바로 알아요. 좋아요.
- 헷갈리는 건 바로 위 초록 버튼이에요. "오늘 기록에 **더하기**"와 "한 판 **더** 적기"가 위아래로 붙어 있어서 두 버튼이 뭐가 다른지 한 번 멈췄어요.
  - 실제 차이: 초록은 게임을 아직 안 고른 상태, 작은 줄은 게임까지 고른 상태.
  - 초록 시트 안에 같은 "할리갈리 한 판 더" 상자가 또 있어서, 같은 일을 하는 입구가 **네 곳**이에요.
- 토스트의 "한 판 더"와 "되돌리기"는 둘 다 밑줄 글자라 크기가 같아요. 잘못 누르면 정반대 일이 생겨요.
- 이렇게
  - 초록 버튼 문구를 "다른 게임·사람 적기"로 바꾸고, 같은 게임은 작은 줄이 맡게 하기.
  - 초록 시트 안 "한 판 더" 상자는 빼기(홈 줄과 겹침).
  - 토스트의 되돌리기는 회색으로.
