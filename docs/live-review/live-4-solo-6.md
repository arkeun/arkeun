## 5회차 것

### 고쳐진 것
- **하루 상세 판 번호**: "1번째 95 / 2번째 102 / 3번째 99 / 4번째 104"로 처음 판부터 맞게 매겨요(07-day, 11-day).
- **한 판 더로 열면 다 펼쳐지던 것**: 새 판이 접힌 채 열려요. 메모·사진·빨간 "이 판 지우기"가 안 보여요.
- **어제 기록 저장 카드의 "공유하기" 두 번**: 이제 "닫기 | 공유하기"예요(09-saved-y).
- **혼자인데 "방금 한 사람 그대로"**: "혼자 한 판 더 적어요"로 바뀌었어요.
- **"다른 게임" 시트 안의 한 판 더 상자**: 없어졌어요(08-other).
- **결과 없이 더하기**: 한 번 물어봐요.

### 그대로인 것
- **첫날 최고 기록 말**: 시트는 "최고 기록!", 홈은 "이날 최고 102점"이에요.
- **최고 기록 토스트**: 104를 깼는데 "캐스캐디아 저장했어요"뿐이에요.
- **공유 카드 숫자 반복**(12-share). 104가 세 번, 4판이 두 번 나와요:
  - "최고 기록 104점!"
  - "캐스캐디아 · 지난 최고 103점"
  - "캐스캐디아 4판 · 최고 104점"
  - 맨 아래 "준혁 · 4판"
- **"다른 게임" 시트 검색 목록**: 혼자이고 보관함에 게임 5개가 있는데도 "많이 기록하는 게임" 카탄(3–4명)부터 나와요(08-other).
- **달력 칸마다 "혼자"**(30-calendar).
- **"승률 –"**: 준혁 탭 76판에서도, 캐스캐디아 게임 화면에서도 그래요.
- **결산**: "76판 · 72일 모였어요", "처음 해본 게임 4개"예요.
- **커플·모임 빈 화면 버튼이 문장 끝에 낌**(31-groups, 32-couple).
- **설정 공개 범위 칩 줄이 항목마다 다름**(33-settings).
- **"✓ 내 보관함", "내 모임"**.
- **하루 상세**: ⋯와 "공유·고치기"가 겹치고, 판마다 "준혁"이 붙어요. 104 줄에 최고 표시가 없어요.
- **월 구분 없음**: "기록 보기" 목록이에요.
