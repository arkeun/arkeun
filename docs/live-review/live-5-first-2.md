- 왜: 커플/친구/모임 → 내 모임/모임 찾기 → 검색 → 정렬, 이렇게 네 겹 아래 회색 안내 한 줄뿐이에요. "빈 모임 흰 화면"은 고쳤다고 했지만 화면 대부분은 여전히 비어 있어요.
- 이렇게: 0개면 검색·정렬을 숨기고 "모임 만들기" 버튼 하나를 가운데에.

### 좋아진 것
- 닉네임 안내가 토스처럼 바로 나와요.
- 예시가 "에릭" 것이라 무섭지 않아요. 띠 덕분에 나가는 길이 한 번에 보여요.
- 저장·공유 카드의 승자가 맞아요. 둘이 했을 때 "다은 2 : 1 수빈"은 한눈에 보여서 좋아요(셋일 때만 문제).
- 처음엔 게임 검색이 열려 있어서 할리갈리를 한 번에 넣었어요.

**계속 쓸까?**
→ 1회차보다 무서운 건 많이 사라졌어요. 하지만 예시에서 적은 기록이 없어진 것과, "오늘 기록하기"가 점심 기록 고치기로 열린 것 때문에 "내 기록이 날아갈 수도 있는 앱"이라는 느낌이 남아요. 이 둘만 고치면 한 달은 써 볼 것 같아요.
