# 9회차 — 준혁(38, 솔로 플레이어), 최신판 3c68856

화면 사진: scratchpad/live4/s11/ (390), s11c/ (칩 한 번 더 시험), 360은 s11/3x-360-*

## 오늘 하루 (일기)
퇴근하고 캐스캐디아 솔로. 처음 열어서 이름 적고 게임 5개 넣고 95점 올림. 바로 한 판 더, 102. 4시간 넘게 쉬었다가 다시 열어도 큰 버튼이 그대로 "캐스캐디아 한 판 더"라 99 올림. 어제 진 스피릿은 "어제"로 넣음. 테라포밍 마스 78점도 하나 넣음. 예전 기록 70판(캐스캐디아 최고 103)이 있는 상태로 104 → "★ 최고 기록", 토스트 "최고 기록이에요", 홈 "★ 최고 104점". 다음 판 100 넣는데 시트 옆에 "최고 103점"이라 떠서 멈칫함. 방금 104 냈는데?

## 판마다 바로 올리기 (탭 수)
- 같은 게임 이어서: 한 판 더 → 숫자 → 더하기 = **2탭 + 숫자**. 점수칸 바로 잡힘. 3판, 4시간 띄운 판, 기록 판 모두 같음. 아주 좋음.
- 다른 게임 하다 캐스캐디아로 돌아올 때: 다른 게임 → 검색칸 → "캐스" → 결과 → 점수칸 → 숫자 → 더하기 = **5탭 + 글자**. 첫 목록이 "많이 기록하는 게임: 카탄…"이라 내 게임이 안 보임(8회차 그대로).

## 8회차 것 중 고쳐진 것
- 한 판 더 시트의 −/+, 배지, "N판" 사라지고 "N번째 판"만 → 깔끔함. − 눌러 새 판 지워지는 문제도 없어짐.
- 첫날 시트에 "최고 기록!"이 안 떠서 토스트·홈과 엇갈리지 않음.
- 기록 판: 시트 "★ 최고 기록" = 토스트 "최고 기록이에요" = 홈 "★ 최고 104점" 셋이 맞음.
- 오늘 카드에서 방금 한 게임이 맨 위로(테라포밍 78점 넣으니 위로, 다시 캐스캐디아 하니 캐스캐디아가 위로).
- 4시간 넘게 띄워도 큰 버튼·번호(3번째 판) 그대로.

## 그대로
- 다른 게임 첫 화면이 카탄·카르카손 등 남의 인기 게임. 내 최근 게임 칩은 검색/선택 뒤에야 보임.
- 하루 상세: 1번째 95 / 2번째 102 / 3번째 99 — ★ 표시 없음, "준혁" 매 줄 반복, ⋯ 중복.
- 360에서 게임 칩 이름 "캐스캐디\n아", "테라포밍\n마스" 줄바꿈.
- 시트 점수칸 아래 "준혁 100"이 방금 친 숫자를 한 번 더 보여 줌.
- 공유 카드·달력·승률·결산·설정 쪽은 이번에 다시 안 봄(바뀐 내용 없다고 보고 넘김).

## 고친 게 만든 새 문제
1. **(짜증, 큼) 오늘 최고를 낸 뒤 시트가 옛 최고를 보여 줌.** 104 낸 다음 판 시트: "최고 103점", 홈은 "★ 최고 104점". 지난날만 비교하는 규칙이라 그렇겠지만, 방금 깬 기록이 시트에서 사라진 것 같음. → 비교 기준에 오늘 앞 판도 넣거나, 표시는 "최고 104점(오늘)"으로.
2. **(짜증, 큼) 칩을 한 번 더 눌러 판을 늘리면 앞 판 점수가 "아직 결과 없음"으로 보임.** 81 적고 칩 다시 누름 → 접힌 줄 "2번째 판 · 아직 결과 없음". 펼치면 81이 남아 있긴 함. 점수 날아간 줄 알고 다시 칠 뻔함. → 접힌 줄에 "준혁 81".
3. **(아쉬움) 칩 한 번 더 누른 뒤 포커스가 칩에 남음.** 바로 숫자 치면 아무 데도 안 들어감. 새 판 점수칸으로 포커스 옮기기.
4. **(아쉬움) 360에서 "6번…"으로 잘림.** −/+를 없애고 남은 단 하나의 글자가 잘림. 점수칸 옆 "★ 최고 기록"이 자리를 먹음. → 최고 표시를 점수칸 아래로.

## 새로 느낀 것
- 테라포밍 마스에 "처음 해봐요" 배지 — 앱에 처음 적은 것일 뿐인데 초보 취급 같음(아쉬움, 작음).
- 큰 버튼 밑글 "점수만 적으면 돼요"가 매번 같음. "6번째 판 · 최고 105점"이면 한눈에 다음 판 목표가 보일 듯(8회차 아이디어 그대로 유효).

## 계속 쓸까?
쓴다. 같은 게임 연속 기록은 이제 BG Stats보다 빠르고 한국어라 편함. 다만 "최고 103점"처럼 기록이 틀려 보이는 순간이 한 번만 더 나와도 점수 앱으로서 믿음이 깎임 — 1·2번은 꼭 고쳐 주면 좋겠음.
