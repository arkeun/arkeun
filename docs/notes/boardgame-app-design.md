- 첫 설계안(2026-11-22): Claude Doc "보드게임 기록·리뷰 앱 설계안 (초안)" https://claude.ai/artifact/1FwNm3dJhDUgwWDVVRzBoB
- 플랫폼 확정(2026-11-22, 사용자): 개발 단계는 웹페이지로 만들고, 출시는 iOS·안드로이드 앱스토어 둘 다.
- 제안 스택: Expo(React Native, Expo Router로 웹 우선) + Supabase, 스토어 등록은 EAS.
- 추가 요구(2026-11-22): 보유 보드게임을 모아 보는 "보관함" 기능 필요 (설계안에 탭·Collection 테이블로 반영).
- 사용자 선호: 디자인과 문구가 "AI스럽지 않게". 실제 앱(Letterboxd, 왓챠피디아, BG Stats 등)을 참고하고, 딱딱한 말 대신 "오늘 뭐 했어요?", "한마디 남기기" 같은 ~해요체 말투.
- 웹 프로토타입 v1(2026-11-22): https://claude.ai/artifact/5EYex8D8c8zAf7P1wjBrVF , 원본 /mnt/project-files/boardgame-app/prototype-v1.html. React+htm 단일 HTML, localStorage 저장, 탭 5개(홈·게임·보관함·기록·나), 샘플 CSV 51개 게임. 박스 이미지 대신 색 블록 커버(외부 이미지 CSP 차단). 위시·필터 제외.
- 사용자 피드백(2026-11-22): 하루 여러 판·여러 게임을 한 번에 쉽게 기록(지난번 멤버 기본값, 게임 탭할수록 판수 증가) / 같은 앱 쓰는 친구와 기록 자동 연동(@아이디, 받은 기록 수락) / 홈에 리뷰 피드 두지 말 것, 리뷰는 게임 상세 아래에만.
- 기록 방식 확정(2026-11-22, 사용자): 하루를 한 장으로(날짜·멤버 한 번), 게임별 판 수, 판마다 승자 따로·메모 선택·점수 선택. 게임이 수만 개라 즐겨찾기 필수(기록 시 즐겨찾기·최근·보관함 먼저, 나머지는 검색). 사용자는 "실제 이용자 입장"에서 생각하길 원함: 모임 중 판 끝날 때마다 이어 적기(임시 저장). 날짜는 자정 지나면 그 날짜(새벽을 전날로 넣지 말 것, 사용자 지시). 멤버는 하루 고정 아님: '오늘 온 사람' 중 게임마다, 필요하면 판마다 참여자를 바꿈.
- 사람 고르기(2026-11-22 요청): 자주 같이 한 사람 칩 + 검색창 하나로 세 종류 처리(앱 친구 / 앱 쓰지만 친구 아님→친구 추가 / 앱 없는 사람→이름만 저장, 나중에 같은 이름 앱 계정과 연결).
- 확장팩(2026-11-22 요청): 확장은 별도 게임이 아니라 본판 아래 묶음(BGG 본판-확장 관계). 판마다 여러 개 동시 선택, 지난번 쓴 확장이 기본값, 다음 판은 앞 판 그대로. 확장 많은 게임은 보유·해본 것 먼저 + '더 보기' 검색. 보관함에 가진 확장 표시.
- 저장소 만들거나 PR 열기 전에는 사용자에게 먼저 물어볼 것.
- 기록 권한·연동 확정(2026-11-22, 사용자): 기록은 쓴 사람만 고칠 수 있음. 친구가 나를 넣은 기록은 "항상 자동 담기" 옵션 없이 알림이 가고, 무시해도 내 기록에 들어옴. 친구는 자기 기록에서 빼기만 가능.
- 중복 기록(2026-11-22, 사용자): 친구와 같은 판을 둘 다 적었으면 합치기 기능 없이 한 사람이 자기 기록을 지우면 됨.
- 직접 추가 게임(2026-11-22): 이름을 치면 다른 사람이 이미 추가한 같은 이름 게임을 먼저 보여주고 그걸 고르게(중복 생성 방지).
- 타이머(2026-11-22): 시작 시각 저장 방식. 도는 중에도 다른 화면 이동·앱 닫기 가능, 하단에 "윙스팬 32분째" 띠, 누르면 기록으로 돌아감.
- 프로토타입 v7에 들어간 것: 순위(공동 등수)·점수로 자동 승자, 설정(공개 범위 전체/친구/나만, 나를 기록에 넣는 것 허용, 알림, 카카오·Apple·Google 로그인 흐름), 차단, 초대 링크, 한마디 신고·숨기기, 한마디에 해본 판 수/안 해봄, 보관함 상태(가지고 있음/빌려줌/팔았음)·산 날짜·가격·박스 사진.
- 승리 조건(2026-11-22, 사용자): 게임별 3가지 "높은 점수 · 낮은 점수 · 임의"(임의=점수는 기록만, 승자 직접). 게임마다 기억, 처음 하는 게임은 다른 사람들이 많이 고른 규칙이 기본(서버 후). 점수 자동 승자·순위는 미리 골라두는 것일 뿐, 직접 누르면 그게 우선.
- 앱 없는 친구 연결(2026-11-22, 사용자): 연결된 날부터의 기록만 친구 기록장에 들어감. 지난 기록은 자동으로 안 넘김. 같은 이름이 많아서 이름으로 자동 매칭·제안하지 않음. 기록한 사람이 그 날 기록을 고칠 때 "이름만 적힌 사람"을 눌러 친구 목록에서 직접 골라 바꿈. "골라 보내기"·친구 화면의 날짜 목록은 사용자가 거절. 리뷰엔 기록이 있을 때만 "12판"(0판·안 해봄 표시 없음, 스포일러 기능 없음).
- 모임(2026-11-22, 사용자 확정): 모임은 멤버 묶음일 뿐. 참석자 고를 때 즐겨찾기처럼 묶여 뜸("모두" 버튼). 기록에 모임 멤버가 한 명이라도 있으면 자동으로 그 모임 기록. 모임 화면은 순위·라이벌·게임별 멤버 승수/승률·연말 결산 축하. 모임 보관함 합치기·모임 안에서 기록 시작은 넣지 말 것.
- 커플(2026-11-22, 사용자): 모임과 별도로 1:1 커플. 참석자 고를 때 커플 줄이 맨 위. 커플 화면은 따로 예쁘게(색 고르기, 처음 만난 날 D+, 다음 100일/주년, 둘만 한 판의 맞대결, 게임별 둘의 전적, 이번 달 우세).
- 사용자가 승인한 추가 기능(2026-11-22, v13에 반영): 오늘 뭐 할까(내 보관함, 인원·시간, 오래 안 한 게임 우선, 하나 골라줘), 룰 설명 영상·룰북 링크, 처음 하는 사람 표시, 항목별 점수 계산판, 선 뽑기·팀 나누기, 하루 요약 카드 공유, 연말 결산, 연속 모임 주·올해 해본 게임 수, 라이벌·게임별 맞대결, 먼지 쌓인 게임(알림 설정), 바코드로 담기(흐름만), 빌려준 게임 누구·며칠째.
- 화면 원칙(2026-11-22, 사용자 강한 피드백): 한 화면에 다 몰지 말 것. 화면마다 온 이유 하나만 바로 보이게, 나머지는 탭으로. 모임 화면 = 이름·인원·최근 한 줄 + [기록|순위(게임 골라 보기)|멤버(검색·정렬)], 결산은 12월에만 배너. 나 탭 = 프로필·요약 3개·결산 버튼 + [게임|사람|한마디]. 예시 데이터 지우기는 설정으로.
- 장소(위치) 항목은 기록에서 뺌(사용자). 모임 100명 대비: 참석자 줄엔 자주 한 6명 + 모임 안 검색, 10명 넘으면 "모두" 숨김, 순위는 5판 이상만·상위 10명 + 전체 보기.
- 캐릭터(2026-11-22, 사용자): 프로필 사진 대신 보드게임 말 캐릭터. 모양(미플·폰·주사위·큐브·토큰·동물, 특정 게임 디자인 아님)·색·표정·모자. 나 탭 캐릭터 누르면 꾸미기(색/표정/모자 탭으로 나눔). 앱 없는 사람은 첫 글자 적힌 미플.
- 목록이 길어질 때(2026-11-22, 사용자): 게임 종류가 많으면 많이 한 5개만 칩, 나머지는 "더보기"+검색. 나 탭·친구 화면 게임별 목록도 상위 몇 개 + 전체 보기.
- 사진·영상(2026-11-22, 사용자): 그날 기록, 판마다, 한마디에 사진·영상 첨부. 목록엔 작은 썸네일, 누르면 크게(영상 재생). 초안에선 영상은 새로고침하면 사라짐(앱에선 서버 저장). 리뷰 쓰기는 게임 화면 리뷰 목록 맨 위 큰 버튼("리뷰 쓰기"/"내 리뷰 고치기"). 첫 플레이 후 리뷰 제안·별점 주기 알림은 넣지 않기로(사용자).
- 평가(2026-11-22, 사용자): "한마디/리뷰" 대신 "평가"로 통일. 버튼 "평가하기"/"내 평가 고치기"(게임 화면 평가 목록 맨 위). 별점 대신 10점 만점(1~10) + 난이도 5단계(선택). 게임 화면에 앱 평균 평점·난이도와 BGG 값(데이터 연결 후) 함께. 평가에 댓글(대댓글 없음), 내 평가 댓글 알림, 댓글 숨기기·신고·차단. 2026-11-23 사용자 "긱 따라하자": 평점 1~10 정수(BGG 기준 말: 형편없어요…최고예요), 평균 소수 한 자리. 난이도=BGG Weight 1~5(가벼움·중간 가벼움·중간·중간 무거움·무거움), 평균 소수 둘째 자리.
