- 기록 확인은 기록장+필터 하나로: 게임 상세 "N판 · 기록 보기", 사람 전적 "같이 한 기록 보기"가 홈 검색으로 연결.
- 보관함 탭: 검색은 전체 게임, 보관함 게임이 먼저. 세그먼트 보관함·즐겨찾기·해본 게임. 선반 보기(실제 비율 박스, 줄마다 선반 판) / 쌓아 보기(가로 띠). 정렬 최근 산·많이 한·오래 안 한·이름(ㄱㄴㄷ 빠른 이동). 빌려준=노란 꼬리표, 팔았음=흑백·필터로만, 확장 보유=뒤에 겹친 박스, 안 해본=초록 점. 무한 스크롤.
- 모임 탭: 커플 위, 고정+최근 순+검색. 모임 화면 기록/순위/멤버, 알림 끄기·홈에서 숨기기.
- 디자인: 글꼴 하나(Pretendard 우선, 웹 초안은 Noto Sans KR), 최소 12px, 승자=진한 굵은 글씨+작은 금색 왕관, 이모지 대신 선 아이콘, 캐릭터 모자 왕관 삭제, 카드는 흰 블록+8px 간격, 누르는 곳 44px.
