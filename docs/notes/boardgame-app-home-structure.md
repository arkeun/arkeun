2026-11-23 사용자 원칙: "기록 앱이니까 기록을 쉽게 쓰고 쉽게 확인하는 게 메인". 세부는 AI 셋(구성/디자인/초안)이 알아서 정하고, 목표 수준의 선택만 사용자에게 묻기. 정리 보고는 구성 담당이 한 번에.
**Why:** 사용자가 "내가 일일이 말할 수 없으니 셋이서 고민해봐"라고 함.

수정된 구성(소식 피드 홈은 폐기):
- 하단 탭: 홈 · 보관함 · 기록(가운데, 평평한 탭, 누르면 시트) · 모임 · 닉네임(에릭). 통계는 닉네임 탭.
- 홈 = 본인 기록장: 맨 위 입력 줄 항상(오늘 기록하기 / 이어 적기 > 타이머 > 모임 요일 "지난번처럼") → 검색(게임·사람·모임) + 월 이동(달력 아님, 목록 안 월 구분선 "11월 · 23판") → 본인이 들어간 기록만 하루 카드 최신순, 친구가 남긴 건 "현우님이 남김".
- 본인이 빠진 모임 기록은 모임 탭의 각 모임 화면에서. 받은 기록은 🔔 알림도.
- 보관함 탭(전 게임 탭, 사용자가 보관함은 특히 예쁘고 감각 있게 원함) = 검색(보관함 게임 먼저, 이어 BGG 전체) + 보관함 · 즐겨찾기 · 해본 게임. 선반 보기(실제 비율 박스+선반 판, 보관함에만)/쌓아 보기(가로 띠), 정렬 4종, 빌려줌 꼬리표, 확장 겹침, 팔았음 흑백, ㄱㄴㄷ 막대.
- 기록 확인은 화면 하나로 통일: 게임 상세 "N판 · 기록 보기", 사람 전적 "같이 한 기록 보기"는 홈 기록장 검색으로 열림.
- 글꼴: 웹 초안 Noto Sans KR(아티팩트는 구글 폰트만), 앱에선 Pretendard.
- 사용자는 과정을 보고 싶어함: 결정 기록은 /mnt/project-files/boardgame-app/review-log.md (문제 → 누가 뭐라고 → 결정).
- 모임 탭 = 고정📌 + 최근 순 + 검색.
관련: [[boardgame-app-design]] [[boardgame-app-scale-v20]]
- 2026-11-23 v30: 모임 탭 약속·대화·기록·멤버(순위는 기록 안), 기록마다 모임 하나 저장(기본=2명 이상 겹치는 모임 중 최다, "모임 없음" 가능; 사용자 결정 카드 답 대기 중, 임시 적용). 커플 추억·기록·전적(머리=둘 사진). 보관함 보관함·사고 싶은·해본 게임. 닉네임 탭 통계·사람·평가. 동네 모임 찾기는 사용자가 "출시 후 다시 정하기"로 결정.
