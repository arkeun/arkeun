- 에릭님(11/24): 수정본은 PR 만들고 기다리지 말고 저장소 main에 바로 올려 사이트(GitHub Pages)에 반영할 것. 챗GPT에 따로 보낼 것 없음(챗GPT는 저장소 메모장을 읽고 의견만).
- 11/24: 이 세션에서 main 직접 push 가능해짐(rebase 후 push). 커플 공간 탭: 홈·같이 할 게임·기록·통계. 에릭 결정(11/24 밤): 같이 할 게임은 반응/분류 없이 '찜(하트)'만, 상대가 찜하면 알림, 커플 사진은 각자 한 장씩 반반 합침. 제미나이 검토는 '제미나이와 자동으로 의논하게 연결하기' 스레드가 돌림(main 올린 뒤 커밋 번호 알려 주기).
- 에릭님(11/24): 수정할 때마다 사진 말고 실제로 눌러 볼 수 있게 보고할 것. 배포(Pages 워크플로 성공) 확인 후 사이트 링크 + "어디를 눌러 뭘 해 보면 되는지" 짧은 확인 순서를 같이 보냄. 브라우저 캐시 때문에 새로고침 안내도.
- 에릭님(11/24): 사이트 링크는 항상 끝에 ?v=날짜-시각(매번 다른 값) 붙여서 줄 것(폰 캐시 때문). 예: https://arkeun.github.io/arkeun/?v=20261124-2235
- 에릭님(11/24 밤) 모임 메모: 일정 참가자 대화는 댓글 말고 채팅방(대화 탭 목록에도, 알림은 참석자만). 일정에 온라인/오프라인 구분 X. "시간 투표로" 같은 말 X → "투표 만들기"(시간·게임 자유 항목). 모임 사진 크게, 카드는 소모임·당근처럼(지역/온라인·인원·대표 사진). "일정 가까운 순" 같은 정렬은 사용 의도(갈 수 있는 모임 찾기: 오프라인은 거리, 온라인은 시간)에 맞출 것. 친구 목록에 모임 사람도 + 어느 모임인지. 숫자는 항상 천 단위 쉼표. 지난 일정 누르면 그날 기록·사진·참석자 페이지.
- 11/25 모임 v62: 모임 안 탭은 홈·일정·기록·멤버 넷(게시판·대화는 홈 줄에서). 참석 말은 "가요 / 아직 몰라요 / 못 가요". 기록 담당이 빠진 판은 p.scribe(개인 화면은 App의 stv로 걸러짐), 테이블은 p.table. 초대 링크는 ?join=(base64 JSON).
