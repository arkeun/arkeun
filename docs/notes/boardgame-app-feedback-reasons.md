2026-11-23 에릭: "메모를 그대로 그만큼만 수정하지 말고 그 메모의 이유를 봐줘".
**Why:** 한 곳만 고치면 같은 문제가 다른 화면에 남아 계속 다시 말해야 함.
**How to apply:** 메모마다 이유를 한 줄로 정리 → 같은 이유에 걸리는 곳을 초안 전체에서 찾아 같이 고침 → 메모별 이유·고친 곳을 짧게 보고.

2026-11-23 에릭: "결국 대부분이 내가 말한 거잖아" → 모든 검토(디자인·구성·QA·UX·사용자 역할)는 에릭이 아직 말 안 한 문제를 매번 최소 10개 먼저 찾고, 보고는 "에릭님이 말한 것 / 우리가 먼저 찾은 것"으로 나눔. 아래 이유 목록이 찾는 기준.

지금까지의 이유:
- 시간(몇 분)·"N게임 N판"·"이번 달 N일 N판"은 중요하지 않음: 기록장은 누구와 무엇을 했고 누가 이겼는지가 핵심, 숫자 통계는 소음. 숫자는 닉네임 탭 통계에만.
- "다 같이 패배", "이 멤버랑" 같은 문구: 실제 앱에서 안 쓰는 말, 뜻이 바로 안 보이는 말은 전부 다시 봄.
- "나" 대신 닉네임: 실제 이용자가 보는 화면이 자연스러워야 함.
- "빼기" 같은 부정 버튼: 눈앞에 두지 말고 ⋯ 안으로.
- 커플: 에릭이 말한 건 "커플은 예쁘게 잘 꾸며 달라"뿐(11/24 정정: 장미색을 모든 곳에 쓰라고 한 적 없음). 분홍·장미색은 커플 화면 안에서만, 밖(홈·에릭 탭·달력·칩)은 일반 글씨 + 작은 하트 하나.
- 모임 수백 개: 항상 최대 규모 기준, 탭 옆 개수는 의미 없음.
- 홈: 달력(작게) 위 + 목록 아래는 에릭이 직접 제안(2026-11-23). 하루를 누르면 그날 결과 화면.
- 협력 게임 결과: 목록 "우리 승 / 게임 승", 여러 판 "우리 2승 · 게임 1승", 입력 버튼 "우리가 이겼어요 / 게임이 이겼어요" (v36).
- 홈 보기: 목록(기본)/달력 중 이용자가 고르고 기억(2026-11-23 에릭 결정). 그날 결과 화면은 어디서 열든 하나.
- 게임 화면 = 정보·평가·질문 탭. 질문은 사람이 답하는 게시판(AI 자동 답 아님), 쓰는 중 비슷한 질문 먼저, 게임 중 켜 두기, 기록 시트에서 "규칙 질문"으로 열고 닫으면 기록 그대로 (v33).
관련: [[boardgame-app-structure-v24]] [[boardgame-app-design]]
- 모임 순위는 판마다 1승으로 셈(2026-11-24 에릭 결정, 같은 날 같은 게임 묶지 않음). 저장 카드는 그날 첫 저장만, 이후 '저장했어요 · 되돌리기' 토스트. 협력 결과 '우리가 이김 / 우리가 짐'.
- 기록은 저장한 판을 몰래 바꾸면 안 됨(11/24 실사용 2회차): 같은 날 다시 기록 = '오늘 기록에 더하기'(새 판만), 사람을 더하거나 빼도 결과 적은 앞 판은 그대로 두고 '앞 판에도 넣기/빼기'를 따로 물음. 예시 중 적은 기록은 내 기록장으로 옮김.
