## 2026-11-22 v20 (초안 댓글 반영 + 대규모)
- 기록 시트는 번호 단계: 1 누구랑 했어요? / 2 무슨 게임 했어요? / 3 사진·영상. 사람 고르기 = 고른 사람 칸(× 빼기) → 검색 → 탭(자주 함께 / 모임 N / ♥ 커플) 하나씩만.
- 규모 가정: 보관함·즐겨찾기 수백, 모임 수십(고정📌·최근 순, 홈엔 4개 + "모임 모두 보기"), 모임별 알림 끄기, 평가 댓글 수백(최신 5개 + "이전 댓글 20개 더"), 댓글 알림은 사람 단위로 묶음("지민님 외 14명").

관련: [[boardgame-app-design]]

## 기본 원칙 (사용자 요청, 2026-11-22)
- 사용자가 하나씩 말하지 않아도 모든 것을 최대 규모로 가정: 모임 수백 개, 모임 안 게임 수백 개, 멤버 수십~수백 명, 기록 수천 판, 게임·보관함·즐겨찾기 수백 개, 댓글·평가·알림 수백 개, 확장 수십 개.
- **Why:** "이걸 내가 하나씩 말해야 해"라며 지침. **How to apply:** 새 화면·목록·통계·알림·결산을 만들거나 고칠 때마다 이 규모로 스스로 점검(상위 N + 더 보기, 검색, 묶기)하고 예시 데이터도 그 규모로.

## v21 (2026-11-22) UX 원칙: 많이 쓰는 사람에게 빠르게
- 참고: BG Stats(이 게임 많이 한 사람 순 정렬, 상태 필터), Letterboxd(날짜 기준 다이어리), KakaoTalk(고정+최근 순).
- 기록 창: "이 멤버랑" 게임 탭이 기본(고른 사람과 자주·최근 한 게임), "지난번처럼" 한 번에 복사, 게임 카드 안 사람은 그 게임 많이 한 순.
- 하루 기록 양식: 요약 한 줄(5게임·7판·시간·모임) + 사람 한 번 + 게임 표(한 줄에 결과, 여러 판은 "나 2승·현우 1승"), 4개 넘으면 3개 + 더 보기, 줄 눌러 자세히.
- 이름 옆 클립 아이콘 없앰. 앱 친구 이름은 눌러서 전적, 앱 없는 사람은 글자만.
- 친구 전적의 게임별 맞대결 줄을 누르면 그 게임 같이 한 기록(날짜·결과)이 펼쳐짐.
- 여러 판 묶음 표기는 '×2' 대신 '스플렌더 2판 · 현우 1승 · 나 1승'처럼 판수와 판별 승을 다 적음(결과 없는 판은 'N판 결과 없음'). 받은 기록도 판마다 승자를 따로 받음.
- 화면에서 '나' 금지: 결과·순위·전적 어디서나 내 닉네임(나 탭에서 바꿈, 예시는 '에릭')으로 표시. 데이터 안에서만 '나'.
- 한 게임 수십 판: 접힌 줄 "스플렌더 30판 · 현우 9승 · 에릭 9승 · 외 3명 · 결과 없음 3", 누르면 사람별 승 칩 + 최근 판부터 5개 + "이전 판 20개 더".
- 홈 시안: 달력형은 사용자가 거절. 비슷한 앱 구조(Strava 홈·지도·기록·그룹·나, Letterboxd 아래 +, Untappd 떠 있는 +) 참고한 3안(소식 피드 / 게임 선반 / 내 기록장) 제시, 추천은 Strava식 소식 피드 + 가운데 기록 탭. 결정 대기.
