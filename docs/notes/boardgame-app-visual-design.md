사용자(2026-11-23): "기록 앱이니까 기록을 쉽게 쓰고 쉽게 확인하는 게 메인", 작은 결정은 Claude들끼리 정하라고 함.

홈 = 에릭 기록장(소식 피드 아님). 탭: 홈·보관함(열면 선반, 검색은 BGG 전체 화면 따로)·기록(가운데, 평평한 탭)·모임·에릭.
- 맨 위 입력 줄: 홈에서 유일한 초록 채움 요소, 폭 꽉 참, 높이 ~56. 이어 적기/타이머/모임 요일이면 같은 자리에서 둘째 줄만 바뀜.
- 그 아래 검색창 한 줄. 월 이동은 화면 위에 붙는 월 머리줄("11월 ▾" + "23판 · 9일")을 눌러서.
- 하루 블록: 테두리 카드 대신 흰 블록 + 8px 회색 간격. 큰 날짜 → 게임 줄(1:1 표지 40px, 판 수, 승자) → 캐릭터 32px 최대 4 + "+N". 사진은 오른쪽 64px 썸네일 + "+N", 큰 사진은 상세에서.
- 친구가 남긴 기록: "현우님이 남김 · 에릭 기록에 들어왔어요" 작은 회색. '내' 금지.

공통: 앱은 Pretendard 하나(웹 초안은 구글 폰트 제약으로 Noto Sans KR, 기기에 Pretendard 있으면 그걸 씀. 초안 v24에 반영 완료) (본문 15/보조 13/최소 12, 숫자 tabular). 승자 금색 글씨 금지(대비 부족) → 이름 진하게 + 작은 금색 왕관. 아바타는 글자 원 대신 캐릭터, 캐릭터 모자 '왕관'은 승자 표시와 겹쳐 제거. 화면 장치에 이모지 금지, 선 아이콘 세트 통일. 표지는 1:1, 잘라내지 않고 맞춰 넣기. 누르는 곳 44pt/48dp 이상. 390·360·412 폭 확인.

보관함(사용자: "더더욱 예쁘고 감각 있게", 2026-11-23): 하단 탭 이름 "보관함", 열면 바로 선반. 세그먼트 보관함·즐겨찾기·해본 게임. 표지 격자 = 선반 보기(박스 실제 비율, 바닥 맞춤, 줄마다 얇은 선반 판, 보관함 세그먼트에만), 목록 = 쌓아 보기(눕힌 박스 가로 띠 28px). 빌려줌 = 메모지 꼬리표("태호"), 확장 = 뒤에 겹친 박스, 팔았음 = 흑백·필터로만. 이름순 ㄱㄴㄷ 빠른 이동, 무한 스크롤, 빈 선반 위 캐릭터. 위 한 줄 "331개 · 이번 달 2개 들임". 검색창 누르면 BGG 전체 검색 화면 따로.

v25(2026-11-23) 사용자 "이게 최선이야?" 뒤 수정: 하루 블록 ~150px(한 화면 3~4일), 캐릭터 24px 가로 겹침, 게임 줄 표지 36px, 공유·고치기·빼기는 ⋯ 하나. 보관함 조작 줄 두 겹(검색 / 세그먼트+거르기 아이콘), 박스 바닥=판 윗면, 줄 간격 18px. 남은 것: ⋯ 메뉴는 카드 안 펼침 말고 시트/팝업, 게임 줄 색은 금색 왕관만(확장·패배는 회색). 웹 초안 스크린샷은 CDN 막혀 있으면 npm pack으로 react/htm 받아 playwright route로 대체.

커플·모임 소개·공유 이미지(2026-11-23 제안): 커플 = 대표 사진(없으면 장미색 그라데이션+두 캐릭터 겹침) 위 "에릭 ♥ 지민"·D+, 요약 한 줄, 탭 추억(3열 사진 격자)·기록(사람 줄 없음, 장미색 날짜·왼쪽 선)·전적. 장미색은 커플 화면 안에서만. 모임 소개 = 16:9 사진+배지+한 줄 소개+회색 메타 줄+"자주 하는 게임" 작은 선반+고정 가입 버튼. 선반 모양 = 앱 전체에서 "게임 모음" 표시. 보관함 공유 이미지 = 1080×1350/1920, 종이색 바탕, 선반 3단 박스 9개, "에릭의 선반".
