## A. 보관함 (에릭님 지적, 원인까지)
1. **박스가 선반 위에 안 놓임.** 캡션 있는 박스만 바닥이 판 윗면에 맞고, 캡션 없는 박스는 약 17px 아래로 내려가 판이 박스 중간을 가로지름. 원인: 캡션 높이가 셀마다 달라 바닥 맞춤이 깨짐. → 셀을 [박스 영역 | 캡션 영역]으로 나누고 캡션 영역은 비어도 같은 높이, 판은 박스 영역 바닥에 붙이기.
2. **박스에 게임 이름이 없음.** 색·무늬 사각형만 있어 무슨 게임인지 모름(72px 미만 글씨 숨김 규칙이 선반까지 적용된 것). → 선반은 박스 아래 한 줄 이름(말줄임) 항상 표시. 실제 박스 그림이 들어와도 이름 한 줄은 유지.
3. **캡션이 박스마다 있다 없다 함**("9월 구입", "+확장"만 드문드문). → 캡션은 정렬 기준 값 한 줄을 모든 박스에 똑같이(또는 아예 없이).
4. **"+확장"이 버튼처럼 읽힘** ① → "확장 2" 회색 글자. 뒤 겹친 박스는 다크에서 선만 보여 어긋난 테두리처럼 보임 → 약간 어두운 채움으로, 위·오른쪽 4px만.
5. **빌려줌 꼬리표("김민호", "소연")가 박스 밖·화면 끝까지 삐져나옴.** → 박스 안쪽 위(right 4px), 기울기 2도 이하. 다크에선 노랑이 화면에서 가장 밝은 점 → 채도 낮춘 크림색.
6. **줄 간격이 들쭉날쭉**(빈 줄처럼 큰 틈). → 줄 간격 고정 18px.
7. **탭마다 모양이 다름**: 보관함만 선반 판, 사고 싶은·해본 게임은 판 없이 박스 높이 제각각이라 바닥선이 춤춤. → 판 없는 탭은 같은 높이 정사각 격자로.
8. **"사고 싶은"에 "해봤어요 40판" 캡션** ① 사고 싶은 목록에선 의미가 다름 → "40판 해봄" 또는 빼기. "해봤어요 11판+…"은 잘림.
9. **세그먼트 숫자가 고른 탭에만 붙어 탭 폭이 바뀌고 글자가 움직임.** → 세 칸 같은 폭(1fr), 숫자는 빼거나 모두에.
10. **공유 선반 이미지에 "예시 게임 128" 같은 가짜 이름.** 사용자가 밖으로 내보내는 이미지라 예시 데이터라도 실제 게임 이름으로.

## B. 어두운 모드
11. 게임 평가 탭 "평가하기" 카드가 밝은 민트 채움(규칙 위반, 가장 눈부심) → accent-fill(#1f7a52) 또는 어두운 면 + 초록 제목.
12. 고른 칩("전체", "오늘", 사람 칩)이 흰 채움 → 고른 칩은 accent-fill, 사람 칩은 어두운 면 + 테두리.
13. 세그먼트 고른 칸이 트랙보다 더 어두움(눌린 것처럼) → 한 단계 밝게(#333936).
14. 알림·선반 이미지 시트: 뒤가 거의 안 어두워져 홈이 그대로 읽힘 → 딤 .6 이상 통일, 시트 위 1px 밝은 선.
15. 초록이 3~4가지(채움, 링크 민트, 평가 카드 민트, 배지) → 채움 1 + 글자 1 토큰만. 약속 카드 전체 초록 테두리 → 왼쪽 바만.
16. 로그인 버튼: 검정 Apple은 다크에서 테두리 사라짐, 흰 Google은 번쩍임 → 각 회사 다크용 공식 모양.
17. "꾸미기" 흰 알약이 다크에서 튐 → 어두운 면 + 테두리, 또는 작은 연필 아이콘.
18. 회색 안내 박스 위 작은 회색 글씨 대비 부족 → 글씨 #a8aea9 이상 또는 박스 바탕 제거.
19. 짙은 남색 표지가 바탕에 묻히고 주황·빨강은 번쩍임 → 모든 표지 1px 옅은 테두리, 다크에서 표지 색 명도 범위 맞추기.
20. 홈 목록에 커플 분홍 왼쪽 바가 연달아 쌓여 목록이 분홍빛 → 홈에선 작은 하트 + 일반 글씨, 분홍은 커플 화면 안에만. 에릭 탭 "♥ 지민 · D+413"도 회색+하트로.
21. 멤버 목록 구분선이 너무 진하고 마지막 줄에도 선(이중선) → 선 .06~.08, :last-child 제거.

## C. 모든 모드·360px
22. **한국어가 단어 중간에서 줄바꿈**("주세/요", "다음 주에 봐/요", "남겼어/요"). 원인: word-break 미설정 → body에 `word-break: keep-all; overflow-wrap: anywhere;`.
23. 결과가 말줄임으로 잘림("스플렌더 30판 · 현우 9승 · 에릭…", "패치워크 2판 · 에릭 1…" 사진 썸네일 때문에 더 좁아짐). 홈 1줄 규칙은 유지하되, 사람 수가 많으면 "현우 9승 외 3명"처럼 줄여 잘리지 않게. 사진 썸네일 있는 카드는 썸네일만큼 결과 줄 폭을 확보.
24. "오늘 기록하기" 둘째 줄이 "목요일 보드게임 화요일 번개 · 오늘 저녁 7시 · 성수 레드…"로 잘림 ① → "오늘 저녁 7시 · 화요일 번개"처럼 시간 먼저, 짧게.
25. 게임 평가 탭 빈 상태: "-" 평점·난이도 상자 + "평가하기" 카드 + "첫 평가 남기기" 버튼(같은 행동 둘) ②⑤ → 평가 없으면 숫자 상자 숨기고 진입점 하나.
26. 게임 화면 표지 위 "스플렌더" + 옆 제목 "스플렌더" 이름 두 번 → 큰 표지에선 표지 안 글씨 빼기.
27. 질문 탭에 "룰 설명 영상 / 룰북" 큰 버튼 둘 ⑤ → 정보 탭으로(질문 탭은 질문만).
28. 설정·멤버 세그먼트 폭이 제각각(왼쪽 몰림, 오른쪽 붙음) → 모든 세그먼트 가로 꽉, 같은 비율.
29. 기록 시트 게임 격자 이름이 한 줄/두 줄 섞여 줄 높이 들쭉날쭉 → 이름 영역 두 줄 높이 고정.
30. 고정 저장 띠 뒤로 내용이 잘려 보임(다크에선 경계가 없어 깨진 화면처럼) → 띠에 시트 바탕색 + 위 1px 선 또는 24px 페이드.
31. 작은 글자 버튼(⋯, ×, "소개 ›", "다른 달 ▾", "고치기", "멤버 관리", "확인")이 44px 미만 → 보이는 크기는 두고 누르는 영역만 44×44.
32. 대화 입력 placeholder "목요일 보드게임에 메시지"가 360px에서 잘림 → "메시지 보내기".
