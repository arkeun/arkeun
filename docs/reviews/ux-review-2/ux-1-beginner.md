# 입문자 수아 (32, 보드게임 카페 세 번 가 봄)

목요일 밤 10시, 회사 동료 지민·현우랑 카페에서 "그 새 카드 모으는 거"를 하고 나왔어요. 지민이 "이 앱에 기록 남겨"라고 해서 깔았어요. 앱을 처음 열었더니 '에릭 기록장'에 남의 기록이 68판이나 있어요. 지우고 다시 들어가서 '새'를 검색했는데 아무것도 안 나와요. 겨우 '윙스팬'을 찾아 눌렀더니 '본판만 +유럽 +오세아니아', '선 뽑기', '승자/순위/협력' 같은 말이 쏟아졌어요. 누가 이겼는지는 고르지도 않았는데 저장이 됐고, 홈에는 "결과 없음"이라고 떠요.

(빈 상태 화면은 기록·보관함을 비운 상태로 직접 찍었어요: scratchpad/u1/e*.png, f*.png)

## 1. 누가 이겼는지 안 물어보고 "결과 없음"으로 저장돼요 (A)
- 화면: u1/f05-picked.png, f07b-saved.png. 게임 카드 안에 '수아·지민·현우·무승부' 칩만 있고 "누가 이겼어요?" 같은 제목이 없어요. 칩은 13px, 높이 32px라 44pt보다 작아요. 안 골라도 '1판 저장하기'가 그대로 눌리고, 홈에는 회색 "결과 없음"만 남아요.
- 비교: BG Stats는 한 판을 적을 때 Winner 칸을 맨 위에 둬요.
- 고칠 방법: 칩 줄 위에 "누가 이겼어요?"(15px, 600) 제목을 붙이고, 칩 높이를 44px로 키워요. 승자를 안 고르고 저장하면 저장 버튼 위에 한 줄로 알려 줘요. "누가 이겼는지 비워 뒀어요 · 그냥 저장 / 고르기".

## 2. 게임 하나 고르면 모르는 말이 한꺼번에 나와요 (A)
- 화면: f05-picked.png, f06-score.png. 카드 한 장에 '승자/순위/협력', '무승부', '본판만 +유럽 +오세아니아 +아시아'(12.5px 점선 칩), '선 뽑기', '처음: 지민, 현우', '타이머 시작', '승리 조건 높은 점수/낮은 점수/임의', '항목별로 계산하기'가 다 보여요.
- 비교: 토스 송금은 금액만 먼저 묻고 메모는 접어 둬요.
- 고칠 방법:
  - 처음 펼친 카드에는 승자 줄과 '+ 점수·시간·메모'만 남겨요.
  - 확장 칩은 보관함에 그 확장이 있을 때만 보여 주고, 접힌 영역 안에서 "확장(추가 카드 묶음) 넣고 했어요"로 바꿔요.
  - '처음: 지민, 현우'는 "지민·현우는 이 게임 처음이에요"로 바꿔요.
  - '협력'은 "다 같이 이기고 지는 게임"으로 풀어 써요.
  - '임의'는 "직접 고를게요"로 바꿔요.

## 3. 이름이 기억 안 나면 게임을 못 찾아요 (A)
- 화면: f04-search-bird.png. '새'로 찾으면 결과가 하나도 없고 "'새' 새로 추가"만 떠요. 그대로 누르면 '새'라는 가짜 게임이 생겨요. 기록이 0개라 '최근' 탭도 비어 있어요(e02-sheet.png).
- 비교: 배민이나 네이버 쇼핑은 검색 결과가 없을 때 비슷한 메뉴나 인기 상품을 보여 줘요.
- 고칠 방법:
  - 게임마다 쉬운 별칭을 붙여요(윙스팬: 새, 알, 카드).
  - 결과가 없으면 "이런 게임인가요?" 제목 아래에 인기 게임 표지 12개를 3열로 보여 줘요.
  - 기록이 0개일 때는 '최근' 탭 대신 '인기 게임' 표지 그리드를 기본으로 보여 줘요.

## 4. 동료 이름을 치고 Enter를 누르면 모르는 사람이 들어가요 (B)
- 화면: f01-typed-person.png, f05-picked.png. '지민'을 치고 Enter를 누르면 첫 결과인 앱 사용자 '@jimin_play'가 골라지고 친구 요청이 나가요. 저장하면 "그 친구 기록에도 바로 들어가요"라고 해요. 소스로도 확인했어요: onEnter가 '이름만 추가'보다 appHits를 먼저 골라요.
- 비교: 카카오톡 친구 추가는 프로필을 보여 주고 한 번 더 확인해요.
- 고칠 방법: Enter는 '이름만 추가'로 동작하게 해요. 앱 사용자는 프로필 사진과 함께 탭해야만 연결되게 해요.

## 5. 첫 화면에서 예시인지 내 건지 헷갈리고, 빈 홈은 줄이 깨져요 (B)
- 화면: 390-01-home.png, u1/e01-home.png.
  - "예시 기록을 넣어뒀어요" 안내가 홈 맨 아래, 수십 판 뒤에 있어서 아무도 못 봐요.
  - 빈 홈에서는 설명 문장이 버튼과 한 줄에 섞여 "수 있어요.[첫 기록 남기기]"처럼 보여요.
  - 문구는 '가운데 기록 버튼'을 가리키는데, 바로 위에 '오늘 기록하기'가 또 있어요. 같은 기능 버튼이 세 개예요.
- 비교: 당근은 처음 열 때 동네 설정 한 단계만 보여 줘요.
- 고칠 방법:
  - 예시 데이터가 있을 때는 홈 맨 위 배너로 알려 줘요. "지금 보는 건 예시예요 · 지우고 시작"(13px, 버튼 44px).
  - 빈 홈의 Empty 버튼은 지우고, 문구는 "누구랑 → 무슨 게임 → 누가 이겼는지만 고르면 끝나요" 3줄로 바꿔요.

## 6. 게임 화면 숫자가 무슨 뜻인지 몰라요 (B)
- 화면: 390-06-game.png.
  - 평점은 '8'만 있고 몇 점 만점인지 안 보여요. 난이도는 '/5'가 붙어 있어서 둘의 기준이 달라요.
  - 'BGG –'가 두 번 나오는데 둘 다 값이 없어요.
- 비교: 네이버 영화는 "★8.2 / 관람객"처럼 만점과 출처를 함께 보여 줘요.
- 고칠 방법:
  - 평점은 "8 / 10"으로 보여 줘요.
  - BGG 값이 없으면 그 줄은 숨기고, 값이 있으면 "해외 평점(BGG)"으로 써요.
  - 난이도는 '쉬움'을 크게(17px) 쓰고, '2.0/5'는 보조 13px로 내려요.

## 7. 빈 '수아' 탭이 틀린 말을 해요 (C)
- 화면: u1/e07-me.png.
  - 0판인데 "오늘 처음 기록했어요"라고 나와요.
  - 통계 칸 이름이 영어 '플레이'예요.
  - "2026 결산 올해 0판" 검은 카드가 화면에서 제일 크게 보여요.
  - 같은 맥락으로, 게임을 고르면 기록 시트 제목이 '이어서 적기'로 바뀌어서 처음 쓰는 사람은 헷갈려요(e04-picked.png).
- 고칠 방법:
  - 0판일 때는 "아직 기록 전이에요"로 바꿔요.
  - '플레이'는 '판'으로 바꿔요.
  - 결산 카드는 1판 이상일 때만 보여 줘요.
  - 시트 제목은 그날 첫 저장 전까지 '오늘 뭐 했어요?'로 유지해요.

## 잘 된 점
- "아직 아무도 안 골랐어요. 혼자 했으면 그냥 넘어가요." 같은 문구가 입문자 눈높이에 딱 맞아요.
- 저장하면 홈에 바로 '처음' 배지와 "기록했어요" 토스트가 떠서, 잘 남았는지 바로 알 수 있어요.
- 빈 보관함(e05-shelf.png)에 고양이 그림, 선반, "첫 게임을 올려 보세요"가 있어서 따뜻하고, 바로 뭘 하면 되는지 보여요.
