# 디자인 민감 20대 (하린) 2회차 검토 (v34)

일요일 오후, 하린은 이번 달을 돌아보려고 홈을 달력으로 바꿨어요. 칸마다 손톱만 한 색 조각에 "예", "예", "예"만 보였어요. 날짜를 눌렀더니 아래에서 시트가 올라왔는데, 뒤에는 같은 기록이 목록으로 또 깔려 있었어요. 질문 탭에서는 첫 질문을 보려고 화면 절반을 내려야 했어요.

직접 찍은 화면: /tmp/claude-0/-home-user/8c8d5c49-f354-5ef1-8cc9-4e713344dc2f/scratchpad/h2/ (390l·360l·390d = 390 라이트·360 라이트·390 다크, w-q1 = 윙스팬 질문 탭)

## 새로 찾은 것

### 1. 달력으로 바꿔도 목록이 그대로 붙어 나오고, 달을 옮기는 방법이 두 가지예요 — A
- **기준**: 5(화면 하나 일 하나), 1(같은 것을 두 방식으로)
- **화면**: 390l-cal, 390l-cal-scroll
- **근거**:
  - "달력"을 누르면 달력 아래에 "11월 / 다른 달 ▾" 목록이 이어져서, 같은 날이 두 번 나와요.
  - 달력은 ‹ › 로, 목록은 "다른 달 ▾"로 달을 옮겨요. 한 화면에 "11월" 제목이 2개예요.
- **비교**: 왓챠피디아 캘린더와 네이버 캘린더는 달력 보기에서 목록을 같이 깔지 않아요. 날짜를 누르면 그날만 보여요.
- **고칠 방법**:
  - 달력 모드에서는 아래 목록을 숨겨요.
  - 달 이동은 달력 머리의 ‹ 11월 › 하나로만 해요.
  - 목록 모드의 "다른 달 ▾"도 같은 ‹ 11월 › 모양으로 맞추면 두 보기가 한 언어가 돼요.

### 2. 달력 칸의 표지 조각이 9px "예 예 예"라 아무것도 안 알려 줘요 — A
- **기준**: 1(알아듣나), 4(하루 30판)
- **화면**: 390l-cal, 390l-cal-prev
- **근거**:
  - `.hc-tiles em`이 14×18px, 글자 9px, 하트가 10px이에요. 최소 12px 원칙보다 작아요.
  - 게임 첫 글자만 써서 "예시 게임 ○○"은 전부 "예"로 나와요. 실제로도 스플렌더·스컬은 둘 다 "스"예요.
  - 3개까지만 보이고 넘친다는 표시가 없어서, 30판 한 날과 3판 한 날이 똑같이 보여요.
- **비교**: Letterboxd 일기 달력은 칸에 포스터 한 장만 크게 넣어요.
- **고칠 방법**:
  - 칸 하나에 그날 가장 많이 한 게임의 표지 1장(칸 너비에 맞춘 둥근 6px 사각)만 넣고, 글자는 빼요.
  - 여러 게임을 한 날은 표지 오른쪽 아래에 작은 겹침 그림자 한 겹을 줘서 "더 있음"만 보여 줘요.
  - 하트는 12px 선 아이콘으로 바꿔요.

### 3. 같은 하루가 "그날 결과"와 "하루 요약", 두 시트로 따로 나와요 — B
- **기준**: 1(같은 것을 두 이름으로), 6(누르는 횟수)
- **화면**: 390l-daysheet, d-daysum
- **근거**:
  - 달력에서 날짜를 누르면 밝은 목록 시트("11월 23일 월요일")가 나와요.
  - 거기서 "공유"를 누르면 다시 어두운 카드 시트("하루 요약")로 바뀌어요.
  - 목록의 ⋯ 메뉴에도 "하루 요약"이 따로 있어요. 같은 날을 세 군데에서 두 가지 모양으로 보여 줘요.
- **비교**: 인스타는 게시물 하나에서 바로 공유 시트를 띄워요. 공유용 화면을 따로 두지 않아요.
- **고칠 방법**:
  - 그날 결과 시트 하나로 합쳐요.
  - 시트 맨 위를 공유 카드 모양(1회차 2번에서 말한 표지 3장 겹침)으로 만들고, 오른쪽 위 공유 아이콘을 누르면 이 카드를 그대로 이미지로 내보내요.
  - ⋯ 메뉴의 "하루 요약"은 지워요.

### 4. 그날 결과 시트에 "점수·메모 없음"과 혼자 떠 있는 ⋯ 가 보여요 — B
- **기준**: 2(필요 없는 정보), 3(기분 나쁜 게 눈앞에)
- **화면**: 390l-daysheet2(10월 2일), 390l-daysheet
- **근거**:
  - 게임 줄 아래에 "점수·메모 없음"이 회색으로 붙어요.
  - 모임 없이 둘이 한 날은 모임 이름 줄이 빠지면서 ⋯ 만 한 줄을 통째로 차지해요(y≈640).
- **비교**: 카카오톡과 토스는 없는 정보를 "없음"으로 적지 않고 줄 자체를 그리지 않아요.
- **고칠 방법**:
  - "점수·메모 없음" 줄을 지워요.
  - ⋯ 는 시트 제목 줄의 닫기 × 왼쪽으로 옮겨요.

### 5. 게임 화면은 탭 위 머리가 화면의 45%라, 탭을 바꿔도 내용이 안 보여요 — B
- **기준**: 5(화면 하나 일 하나), 4(질문 수백 개)
- **화면**: 390l-game-질문, 390l-game-평가
- **근거**:
  - 표지, 정보 3칸, 버튼 3개를 지나야 탭이 y≈380에 나와요.
  - 질문 탭의 첫 질문은 y≈470에서 시작해요.
  - 질문이 수백 개여도 탭이 위에 붙어 있지 않아서, 다른 탭으로 가려면 맨 위까지 다시 올라가야 해요.
- **비교**: 왓챠피디아 작품 화면과 당근 프로필은 탭을 스크롤하면 위에 붙여 둬요.
- **고칠 방법**:
  - 정보 3칸(인원·시간·나이)은 "정보" 탭 안으로 옮겨요.
  - 탭 줄은 `position: sticky; top: 0`으로 붙여요.
  - 그러면 탭이 y≈280으로 올라와요.

### 6. "평가하기"가 한 화면에 두 번, 다른 모양으로 있어요 — B
- **기준**: 5, 1
- **화면**: 390l-game-평가
- **근거**:
  - 탭 위에는 흰 테두리 버튼 "평가하기"가 있어요.
  - 평가 탭 안에는 진초록 배너 "평가하기 · 평점만 줘도 돼요. 난이도, 사진·영상도 넣을 수 있어요"가 또 있어요.
  - 난이도 표기도 정보 영역은 "2.0/5", 평가 탭은 "2.00/5"로 달라요.
- **비교**: 왓챠피디아는 별점 넣는 곳이 한 군데예요.
- **고칠 방법**:
  - 평가 탭 안의 초록 배너를 지워요.
  - 평가가 하나도 없을 때만 빈 화면 안에 "첫 평가 남기기" 버튼을 둬요.
  - 난이도는 소수 한 자리(2.0)로 통일해요.

### 7. 질문 탭의 주제 칩과 "도움 많은 순 ▾"가 겹치고, ▾인데 누르면 순서만 돌아가요 — B
- **기준**: 1(실제 앱에선 안 하는 방식), 4(주제 칩 수십 개)
- **화면**: w-q1(윙스팬 질문 탭)
- **근거**:
  - 칩 줄 끝의 "오세아니…"가 정렬 글자 밑으로 잘려 들어가요.
  - ▾는 펼쳐지는 메뉴처럼 보이는데, 코드는 누를 때마다 도움 많은 순 → 최신 → 답 없는 순으로 돌기만 해요(`setSort` 순환).
- **비교**: 당근과 네이버 카페는 ▾를 누르면 고를 수 있는 목록 시트가 떠요.
- **고칠 방법**:
  - 정렬은 칩 줄 위 오른쪽에 따로 한 줄로 빼요.
  - 누르면 바닥 시트에 "도움 많은 순 / 최신 순 / 답을 기다리는 질문" 3개를 체크 표시와 함께 보여 줘요.
  - 칩 줄은 가로 스크롤 끝에 16px 여백을 줘요.

### 8. 질문 쓰기 창의 안내 글이 두 줄로 넘치고, "닫기"가 회색 글자 하나예요 — C
- **기준**: 1
- **화면**: 390l-qa-ask
- **근거**:

  - "닫기"는 13px 회색 글자이고, 옆에는 꽉 찬 "질문 올리기" 버튼이 있어서 무게가 안 맞아요.
- **고칠 방법**:
  - 안내 글은 "어떤 규칙이 헷갈렸어요?"로 줄여요.
  - 닫기는 입력 카드 오른쪽 위 × 아이콘으로 바꿔요.

## 1회차 미반영
- 하루 요약 카드가 아직 글자 목록뿐이에요. 표지와 왕관이 없어서 공유할 맛이 안 나요(d-daysum).
- 다크 모드 커플 머리 배경을 여전히 #fff와 섞어요. `.chero2`가 그대로예요.
- 글자 크기 종류가 24종에서 26종으로 오히려 늘었어요. border-radius는 16종 그대로예요.
- 게임 화면 버튼 3개가 아직 모양이 제각각이에요. 윙스팬에서는 "평가 고치기"와 "가지고 있어요"가 같은 연초록이라, 뜻은 다른데 겉모양이 같아요.
- 커플 화면만 원형 뒤로 버튼과 44px D-day를 써요.
- 보관함 머리에 아이콘 2개와 글자 버튼 "뭐 할까?"가 섞여 있어요.

## 잘 된 점
- 달력에서 커플과 한 날만 장미색 칸에 하트를 넣은 건 귀엽고, 다크에서도 색이 잘 가라앉아요.
- "이번 달 2개 들임"과 시간 숫자가 빠지니 보관함 머리와 게임 화면 여백이 한결 숨 쉬어요.
