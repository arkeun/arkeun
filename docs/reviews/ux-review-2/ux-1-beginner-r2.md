# 입문자 수아 · 2회차 (v34)

윙스팬을 하는데 "갈색 능력은 언제 쓰는 거야?"로 말다툼이 났어요. 수아는 기록 시트에서 작은 '규칙 질문' 링크를 찾아 눌렀어요. 그런데 질문 목록 위에 '전체·본판·유럽 확장·오세아니…' 칩이 겹쳐 있고, '도움 많은 순▾'은 눌러도 목록이 펼쳐지지 않고 글자만 바뀌어요. 정작 보고 싶던 룰 설명 영상은 이 화면에 없어요.

새로 찍은 화면은 scratchpad/u2/ 에 있어요(g01~g06, h01~h03).

## 새로 찾은 것 (에릭님이 아직 말하지 않은 것)

**N1. 달력 칸 게임 표시가 '예', '테' 한 글자예요 · 기준 1, 4 · B**
- 화면: g01-cal.png
- 근거:
  - 칸마다 게임 이름 첫 글자 하나만 9px로 보여요(.hc-tiles em, 14×18px). 최소 글자 크기 12px보다 작아요.
  - 첫 글자가 같은 게임은 '예 예 예'처럼 구분이 안 돼요.
  - 하루 30판이어도 3칸만 보이고, 더 있다는 표시가 없어요.
- 고칠 방법:
  - 글자 대신 게임 표지 색 점(8px)을 최대 3개 보여 줘요.
  - 더 있으면 "+5"(12px)를 붙여요.
  - 이름은 그날을 눌렀을 때만 보여 줘요.

**N2. 달력으로 바꿔도 밑에 목록이 그대로 붙어 있어요 · 기준 5 · B**
- 화면: g01-cal.png. 달력 아래에 '11월 · 23일 목요일 보드게임…' 목록이 다시 나와요. 그래서 '목록/달력' 버튼이 바꾸기가 아니라 '달력 더하기'처럼 동작해요.
- 고칠 방법: 달력 보기에서는 목록을 숨겨요. 날짜를 누르면 그날 결과 시트만 열어요.

**N3. 그날 결과 시트에 "점수·메모 없음"이 게임마다 붙어요 · 기준 2, 3 · B**
- 화면: g02-day.png, g03-day-from-list.png
- 근거:
  - 게임마다 회색 "점수·메모 없음" 줄이 붙어요.
  - 스플렌더 칩 줄에 '결과 없음 3' 칩이 있고, 판 목록 맨 위가 '30판 결과 없음'이에요.
  - '없음'이 화면에서 가장 많이 반복되는 말이에요.
- 고칠 방법:
  - 내용이 없는 줄은 아예 그리지 않아요.
  - '결과 없음 N' 칩은 빼요.
  - 결과 없는 판은 판 번호만 보여 줘요.

**N4. 그날 결과 시트의 큰 초록 버튼이 '고치기'예요 · 기준 5, 6 · C**
- 화면: g02-day.png. 아래 버튼이 '공유 | 고치기'인데, 초록 주 버튼이 '고치기'예요. 보러 들어온 화면에서 제일 눈에 띄는 버튼이 수정이에요.
- 비교: 인스타그램은 게시물 수정을 ··· 메뉴 안에 둬요.
- 고칠 방법: 주 버튼은 '공유하기' 하나만 두고, '고치기'는 오른쪽 위 ··· 메뉴로 옮겨요.

**N5. 같은 기능을 서로 다른 이름으로 불러요 · 기준 1 · B**
- 사람 고르기 탭은 '자주 같이 한'인데, 게임 고르기 탭은 '같이 자주 한'이에요(390-03-record-sheet.png). 어순만 달라요.
- 질문 기능 이름이 네 가지예요:
  - 게임 화면 탭: '질문'
  - 기록 카드 링크: '규칙 질문'
  - 질문 화면 제목: '윙스팬 규칙 질문'
  - 질문 버튼: '~에 대해 물어보기'
- 보관함도 이름이 세 가지예요: 게임 화면 버튼 '가지고 있어요', 정보 탭 카드 '에릭 보관함 적기', 아래 탭 '보관함'.
- 고칠 방법:
  - 탭 이름은 둘 다 '자주 같이 한'으로 맞춰요.
  - 질문은 어디서나 '규칙 질문'으로 불러요.
  - 버튼은 '보관함에 있어요'로 바꿔요.

**N6. 질문 화면 필터 칩과 정렬 버튼이 겹치고, 정렬은 누를 때마다 글자만 바뀌어요 · 기준 1, 4 · B**
- 화면: h02-qa-layer.png
- 근거:
  - 390px에서 '오세아니…' 칩이 '도움 많은 순▾' 아래로 잘려 들어가요.
  - ▾ 표시가 있는데 목록이 펼쳐지지 않아요. 누를 때마다 '도움 많은 순 → 최신순 → 답 없는 것 먼저'로 돌아가요.
  - 확장이 5개 이상이면 select로 바뀌어서, 게임마다 필터 모양이 달라요.
- 비교: 당근, 네이버 카페는 정렬을 누르면 아래에서 선택 시트가 올라와요.
- 고칠 방법:
  - 정렬은 필터 칩 줄 위 오른쪽에 따로 두고, 누르면 선택 시트가 열리게 해요.
  - 필터는 항상 가로 스크롤 칩으로 통일해요.

**N7. 게임하다 막혔을 때 여는 질문 화면에 룰 영상이 없어요 · 기준 6, 입문자 · A**
- 화면: h02-qa-layer.png, g04-info-scroll.png
- 근거:
  - '룰 설명 영상 · 룰북'은 게임 화면 정보 탭에만 있어요.
  - 기록 중에 여는 질문 화면에서 영상을 보려면 기록 시트를 닫고, 보관함에서 게임을 찾아 정보 탭으로 가야 해요. 4번 넘게 눌러야 해요.
  - 처음 하는 사람에게는 질문 글보다 영상이 먼저예요.
- 고칠 방법:
  - 질문 화면 제목 바로 아래에 "룰 설명 영상 보기 ›"(15px, 44px 줄)를 넣어요.
  - '처음 해봐요' 배지가 있는 게임이면 이 줄을 맨 위에 보여 줘요.

**N8. 처음 보는 말이 아직 남아 있어요 · 기준 1 · B**
- '화면 켜 두기'(h02): 무엇을 켜 두는지 바로 안 와요.
- '고른 답'(h03): 누가 골랐는지 모르겠어요.
- 난이도 '2.00 / 5 · 중간 가벼움'(g05-rate.png): 소수점 두 자리이고, '중간 가벼움'이 어색해요.
- 고칠 방법:
  - '화면 켜 두기' → "화면 안 꺼지게"
  - '고른 답' → "질문한 사람이 고른 답"
  - 난이도는 소수점 한 자리로 줄이고, 5단계를 '쉬움 · 조금 쉬움 · 보통 · 조금 어려움 · 어려움'으로 바꿔요.

**N9. 평가 탭에 '평가하기'가 두 번 있어요 · 기준 5 · C**
- 화면: g05-rate.png. 위쪽 버튼 줄에도 '평가하기'가 있고, 평가 탭 안에도 큰 초록 카드 '평가하기'가 있어요.
- 고칠 방법: 위쪽 버튼 줄에서 '평가하기'를 빼고 '기록하기 | 보관함에 있어요' 두 개만 남겨요.

## 1회차 미반영
- 게임 카드의 '본판만 +유럽…' 확장 칩과 '선 뽑기'가 그대로예요(h01).
- 이름이 기억 안 날 때 찾는 방법이 없어요('새'로 찾으면 결과 없음, 별칭과 인기 게임 표지 없음).
- 빈 홈 문구가 아직 '가운데 기록 버튼'을 가리키고, 버튼이 세 개 겹쳐요.
- 평점 '8' 옆에 만점 표시가 없고, 'BGG –'가 그대로예요(g05).
- 기록이 0판인 수아 탭에 "오늘 처음 기록했어요", '플레이'가 그대로이고, 기록 시트 제목이 '이어서 적기'로 바뀌는 것도 그대로예요.

## 잘 된 점
- 질문을 쓰는 칸이 검색 칸도 겸해서 "비슷한 질문이 먼저 떠요"가 보여요. 같은 질문이 쌓이는 걸 막아 줘요.
- 기록 시트에서 '누가 이겼어요?'가 생겼고 이름 칩이 커져서(h01) 입문자도 바로 골라요.
