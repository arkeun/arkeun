# 큰 글씨 50대 정호(54) 3회차 검토 (v45)

화요일 밤 10시. 정호님이 스플렌더 두 판을 적다가 한 판을 잘못 넣은 것 같아서 "버리기"를 눌러요. 아무 일도 안 일어나는 것 같아서 두 번, 세 번 더 눌러요. 결국 닫고 다시 열어요. 다음 주에 혼자 연습한 판을 적으려는데 "혼자 했어요"는 초록 글씨 한 줄이라 손가락에 안 걸려요. 사람 칩을 × 다섯 번으로 하나씩 지워요.

새 화면은 직접 눌러 찍었어요(기본, 125% 확대, 다크): scratchpad/ux3r3/. 찍은 화면은 저장 뒤 한 장(모임·혼자), 앞 판처럼, 혼자 했어요, 날짜별|순위, 빈 홈·빈 보관함이에요. review-log.md, eric-said.md, 다른 담당 r2와 겹치는지 grep으로 확인했어요("버리기", "혼자 했어요", "지난번처럼: ·", 빈 홈 버튼 두 개는 기록 없음).

## 새로 찾은 것

### 1. "버리기"를 눌러도 확인창이 화면 밖에 떠요 (A) [기준 3·6]
- 화면: light-g1-prev.png, light-g3-discard.png, light-h1-discard-ask.png
- 근거: v41부터 저장 버튼 줄이 아래에 고정되면서 바로 옆에 "버리기"가 붙었어요. 누르면 "적던 기록을 버릴까요? [버리기][취소]" 확인창이 시트 내용 맨 끝에 생겨요. 실측 y=1503px로 화면(844px) 밖이고, 고정된 버튼 줄 아래에 깔려요. 눌러도 반응이 없는 것처럼 보이니 정호님은 여러 번 누르게 돼요. 고칠 때도 같은 자리에 빨간 "이 날 지우기"가 "고친 내용 저장" 바로 옆에 있고, 그 확인창("되돌릴 수 없어요")도 화면 밖에 떠요.
- 비교: 카카오톡과 토스는 지우기 확인을 화면 가운데 팝업으로 띄우고, 저장 버튼 옆에 지우기를 두지 않아요.
- 고칠 방법: 고정 줄에는 "N판 저장하기"만 꽉 차게 둬요. "버리기"는 시트 오른쪽 위 ⋯ 안의 "적던 기록 버리기"로 옮기고, "이 날 지우기"는 그날 결과 화면의 ⋯ 안으로 옮겨요. 확인은 화면 가운데 팝업으로 띄우고 버튼 높이는 48px으로 해요. 문구는 "적던 기록을 버릴까요?"에 [계속 적기](주 버튼) / [버릴게요]예요.

### 2. "혼자 했어요"가 67×18px 글씨 링크예요 (B) [기준 6·1]
- 화면: light-b0-sheet.png (125%에서는 zoom-b0-sheet.png, 84×22)
- 근거: 사람을 고른 뒤에만 "에릭 포함 3명 · 혼자 했어요"라는 13px 초록 글씨로 줄 끝에 붙어 나와요. 높이가 18px이라 바로 위 × 칩이나 아래 입력칸이 대신 눌려요. 누르면 고른 사람이 한 번에 다 빠지는데, 되돌리기 안내도 없어요.
- 비교: BG Stats는 "Solo" 항목이 사람 목록과 같은 크기의 줄로 있어요.
- 고칠 방법: "자주 같이 한" 칩 줄 맨 앞에 칩 "혼자"(높이 44px)를 둬요. 누르면 칩이 켜지고 사람 칩이 빠져요. 다시 누르면 아까 고른 사람이 돌아오게 해요.

### 3. 혼자 한 뒤 홈 첫 줄이 "지난번처럼: · 스플렌더"로 나와요 (B) [기준 1]
- 화면: zoom-s3-solo-saved.png (홈 배경)
- 근거: 지난번에 같이 한 사람이 없으면 사람 자리가 비고 가운뎃점만 남아요. 글자가 큰 화면에서는 이게 오타처럼 바로 보여요.
- 고칠 방법: 사람이 없으면 "지난번처럼: 혼자 · 스플렌더"로 써요.

### 4. 빈 홈에 같은 일을 하는 초록 버튼이 두 개예요 (B) [기준 5·1]
- 화면: light-d1-empty-home.png
- 근거: 맨 위 "오늘 기록하기"(초록, 화면 폭 전체)가 있고, 가운데에 또 "첫 기록 남기기"(초록)가 있어요. 처음 연 50대는 둘이 다른 기능인 줄 알고 어느 걸 눌러야 하는지 망설여요.
- 고칠 방법: 가운데 초록 버튼은 지워요. 빈 칸 안내는 "위 '오늘 기록하기'로 첫 판을 적어 보세요."로 하고, 그 아래에 "BGG에서 기록·보관함 가져오기" 테두리 버튼 하나만 둬요.

### 5. 모임 순위 한 줄에 숫자가 세 개 있어요 (C) [기준 2]
- 화면: light-c2-grp-rank.png, zoom-c2-grp-rank.png
- 근거: 한 줄이 "11승 / 26판 · 42%"예요. 순서는 %로 매기는데 승·판 숫자가 앞에 있어서, 4위(8승)가 5위(9승)보다 위인 이유를 바로 알 수 없어요. 125%에서는 이름과 숫자가 붙어서 한 덩어리로 읽혀요. 아래에는 설명이 세 문장 붙어 있어요.
- 고칠 방법: 오른쪽에는 "42%" 하나만 16px 굵게 둬요. "11승 · 26판"은 이름 아래 13px 둘째 줄로 내려요. 설명은 "5판 이상 한 사람만 나와요" 한 문장으로 줄여요.

## 1·2회차 미반영
- 125%에서 "목록/달력" 버튼이 "목/록", "달/력"으로 쪼개지고 제목이 "에릭 기록/장"으로 꺾여요(zoom-s3, zoom-a4). `.vsw button`에 nowrap을 줘야 해요.
- 44px 미만 누르는 곳이 남아 있어요: 목록/달력 46×36, 모임 기록 사람 이름 39×20, 게임 줄 높이 36, 작은 칩 30, 기록 시트 "규칙 질문" 55×18, 확장 칩·"+ 점수·사진·메모"·"선 뽑기" 높이 27.
- 보관함 공유·바코드 버튼이 아직 아이콘만 있어요.

## 잘 된 점
- "앞 판처럼: 에릭 승"이 44px 높이로 바로 보이고, 끝난 판이 "1번째 판 · 에릭 승 ›" 한 줄로 접혀서 승자 칩을 잘못 누를 일이 크게 줄었어요.
- 저장 뒤 한 장이 "오늘의 승자 에릭"을 큰 글씨로 보여 줘요. 125%와 다크에서도 깨지지 않아요.
