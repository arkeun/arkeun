# 2회차 (v34): 에릭님이 아직 말하지 않은 문제

다섯 명(입문자 수아 · 하루 수십 판 동훈 · 큰 글씨 정호 · 디자인 하린 · 가족 은정)이 v34를 다시 직접 눌러 봤어요. 에릭님이 이미 말한 것(scratchpad 목록)은 뺐어요. 괄호 안은 찾은 사람 수, [ ]는 review-log 기준 번호예요.
원문: 같은 폴더 *-r2.md

## 우리가 먼저 찾은 것 (16개)
1. **달력 칸 글자가 9px 첫 글자 하나뿐이에요** ("예 예 예", "스·코·팬"). 30판 한 날과 3판 한 날이 똑같아 보여요. (4명) [1·4·7]
   → 그날 대표 표지 1장, 여러 게임이면 뒤에 겹친 그림자. 글자는 넣지 않아요. 칸은 `repeat(7, minmax(0,1fr))`로 폭을 고정해요.
2. **달력으로 바꿔도 아래에 목록이 그대로 나와요.** 같은 날이 두 번 보이고, 달 이동도 ‹ › 와 "다른 달 ▾" 두 가지예요. (3명) [5·1]
   → 달력 보기에서는 목록을 숨겨요. 달 이동은 ‹ 11월 › 하나로 해요. 목록/달력 전환과 제목에는 줄바꿈 금지(125%에서 "목/록").
3. **그날 결과에 "없음"이 가장 많아요.** "점수·메모 없음"이 게임마다 붙고, "결과 없음 3" 칩도 있어요. (4명) [2·3]
   → 둘 다 지워요. 결과를 안 고른 판만 "승자 고르기 ›"로 보여 줘요.
4. **그날 결과에서 판 하나를 고칠 수 없어요.** 34판짜리 날 전체 시트를 열어야 해요. 보러 온 화면인데 큰 초록 버튼은 "고치기"예요. (2명) [6·5]
   → 판 줄을 누르면 그 판만 고치는 작은 시트가 열려요. 큰 초록 버튼은 없애고, ⋯ 안에 "이 날 전체 고치기"를 둬요.
5. **"지난번처럼"이 이미 고른 사람을 말없이 덮어써요.** 서윤·도윤·남편을 넣은 뒤 누르면 지민·현우·소연·태호로 바뀌어요. (1명) [6·3]
   → 사람을 한 명이라도 고르면 이 버튼은 숨겨요.
6. **같은 것을 여러 이름으로 불러요.** (3명) [1]
   - 사람 탭 "자주 같이 한" / 게임 탭 "같이 자주 한" → 둘 다 "자주 같이 한"
   - "질문 / 규칙 질문 / 윙스팬 규칙 질문 / ~에 대해 물어보기" → "질문" 하나
   - 협력 결과: 입력은 "게임이 이겼어요", 목록은 "패배" → 목록도 "우리 승 / 게임 승"
7. **게임 화면에 "평가하기"가 두 번 있어요.** 위 버튼 줄과 평가 탭 안이에요. (4명) [5]
   → 위 버튼 줄에서 빼요(평가 탭 맨 위가 원래 자리). 난이도 2.0과 2.00 표기도 하나로 맞추고, 값이 없는 "BGG –"는 숨겨요.
8. **질문 탭 정렬 "도움 많은 순 ▾"이 누를 때마다 순서만 바뀌어요.** ▾ 모양과 동작이 다르고, 확장 칩 끝이 그 밑으로 잘려요. (3명) [1·4]
   → 정렬은 누르면 3개 중 고르는 아래 시트로 바꿔요. 칩 줄은 가로 스크롤만 하고, 정렬은 그 위 오른쪽에 둬요.
9. **게임 중 연 질문 화면에 룰 설명 영상이 없어요.** 영상은 정보 탭에만 있어서 4번 넘게 눌러야 해요. (1명) [6]
   → 질문 화면 맨 위에 "룰 설명 영상 · 룰북" 한 줄을 둬요.
10. **기록 시트의 "규칙 질문" 링크가 "3명" 바로 옆이라 잘못 눌려요.** (1명) [6]
   → 게임 카드 ⋯ 안으로 옮겨요(처음 구성안 자리).
11. **"30판"이 한 화면에서 두 뜻으로 쓰여요.** "스플렌더 30판"은 30번 했다는 뜻이고, "30판 결과 없음"은 30번째 판이에요. (1명) [1]
   → 판 순서는 "30번째"로 적어요.
12. **"이전 판 20개 더 보기 · 모두 34판"** 숨은 판은 29개인데 20개라고 하고, 34판을 또 보여 줘요. (1명) [1·2]
   → "이전 판 더 보기"로 바꿔요.
13. **하루를 보는 화면이 두 모양이에요.** 그날 결과 시트, 하루 요약 시트, ⋯의 하루 요약이 따로 있어요. (1명) [5]
   → 그날 결과 시트 하나로 합쳐요. 공유는 그 시트 오른쪽 위 아이콘으로 해요.
14. **질문 쓰기 창 안내가 두 줄로 꺾이고, "닫기"는 13px 회색 글자예요.** (1명) [1]
   → 안내는 "어떤 규칙이 헷갈렸어요?", 닫기는 × 아이콘으로 바꿔요.
15. **저장 토스트가 360px에서 잘려요.** "…벌써 41번째 · 현우, 지…" (1명) [2]
   → "스플렌더 벌써 41번째"만 남기고(가족 검토자가 좋아함), 오른쪽에 "되돌리기"를 둬요.
16. **분홍 칸·10px 하트가 무슨 뜻인지 설명이 없어요.** (1명) [1]
   → 처음 한 번만 달력 아래에 "분홍 칸은 지민님과 한 날이에요"를 보여 줘요. 하트는 12px 선 아이콘으로 바꿔요.

## 반영하지 않기로 한 것
- 난이도 이름 "중간 가벼움"을 바꾸자는 의견: 에릭님이 BGG 기준으로 정한 말이라 그대로 둬요.
- 기록 시트에서 질문을 아예 빼자는 의견: 에릭님이 "게임하면서 켜 두는 창"을 원해서 ⋯ 안으로만 옮겨요.
