## 1·2회차 미반영
- 게임 카드의 '본판만 + 도시들', '선 뽑기', '처음: 민지, 도현'이 그대로예요(c02b).

- 질문 화면의 '화면 켜 두기', '고른 답', '도움 많은 순▾'이 그대로예요.
