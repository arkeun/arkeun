## 유형별 결정
### 하루 수십 판 (동훈)
- 끝난 판은 한 줄로 접기("27판 · 지민 승 ›"), 펼침은 마지막 판만. 게임 타일 누르면 새 판으로 스크롤. 게임 카드 머리에 "현우 12 · 에릭 9 · 지민 7".
- 저장 버튼 시트 아래 고정(sticky, 52px, "3판 저장하기").
- 게임 단위로 사람을 빼면 **이번 판부터** 빠짐(앞 판 사람·승리 유지). 판 머리에 "사람 3명 ›".
- 이어 적는 중이거나 지난번과 같은 멤버면 1번(누구랑)을 한 줄로 접기 "현우·지민이랑 · 바꾸기".
- 저장 토스트에 "되돌리기" 5초.
- 타이머는 시트에 하나, 판마다 붙이지 않음. 타이머 띠가 탭바와 겹치는 것 고침.

### 입문자 (수아)
- 게임을 고르면 처음엔 승자 줄 + "+ 더 적기"만. 확장 칩은 그 확장을 가졌거나 해봤을 때만, 선 뽑기·승리 조건·점수 계산은 "+ 더 적기" 안.
- 게임 검색 결과가 없으면 "새로 추가"보다 위에 인기 게임 표지 줄. 별칭 검색(한글 별명)은 데이터 연결 때.
- 예시 데이터 안내는 홈 맨 위 작은 띠 "예시 기록이에요 · 지우기".
- 게임 화면 평점 "8 / 10", 값 없는 BGG 줄은 숨김.
- 빈 닉네임 탭 "오늘 처음 기록했어요"(0판일 때) 등 빈 상태 문구 정리, 영어 '플레이' → '판'.

### 큰 글씨 50대 (정호)
- 기록 시트 게임 타일 이름 `word-break: keep-all`, 그리드 `repeat(auto-fill, minmax(76px,1fr))`. 세그먼트 줄바꿈 금지.
- 홈 게임 한 줄: 잘릴 때 **승자가 아니라 같이 한 사람부터** 잘리게 순서 정리(게임 · 판수 · 왕관 승자 · 사람). 하루 블록 높이(~150px, 한 화면 4일)는 유지 → 2줄로 늘리지 않음.
- 하루 펼침 화면에 "고치기" 글자 버튼. 보관함 머리 아이콘은 길게 누르면 이름(접근성 이름은 이미 있음). 모임 핀 아이콘 → "고정" 글자.
- 에릭 탭 설정에 "글자 크기 보통/크게"(C, 이번엔 자리만).

### 디자인 민감 20대 (하린)
- 표지 무늬 6종 → 원호 하나 + 위→아래 20% 어두워지는 그라데이션. 48px 미만 표지는 첫 글자 하나만.
- 다크 모드: 커플 머리 배경을 --bg와 섞고 이름 글자색 고정, 결산 카드는 --surface + --accent 테두리.
- 게임 화면 버튼: 주 버튼(기록하기)만 채우고 평가하기·가지고 있어요는 같은 보조 모양, 켜지면 체크와 글자색만 초록. 평점 초록 상자 제거.
- 커플 화면 뒤로·설정 버튼을 공통 모양으로, D+ 32px.
- 하루 요약 공유 카드에 표지·왕관, 선반 이미지 15개(단마다 5), 결산에 "스토리로 공유".
- 글자 크기 단계(24종→12/13/15/17/20/24/32), 둥근 정도(6/10/14/999) 정리는 이번에 같이.
- 보관함 360px 부제 "246개 · 이번 달 +2".

### 아이 있는 가족 (은정)
- "다 같이 패배" → "이번엔 게임이 이겼어요"(협력 게임 진 날). 순위 입력의 "졌어요"는 빨강 대신 회색.
- 앱 없는 사람도 기록한 사람이 캐릭터를 정할 수 있게(사람 시트 "캐릭터 정하기"). 첫 글자 4.5px → 11px 이상.
- 하루 머리줄: 모임 없음으로 저장한 판이 다른 모임 이름 아래 섞이지 않게, 모임이 없으면 같이 한 사람 이름("서윤·도윤이랑").
- 앱 쓰는 사람이 한 명뿐인 모임은 약속·대화 탭 숨김(기록·멤버만). 모임 만들기 이름 예시에 "우리 집".
- 사람 시트 큰 숫자 잘림 → 22px.
- 사진 칸 옆 "친구에게 보여요 ›"(C).
