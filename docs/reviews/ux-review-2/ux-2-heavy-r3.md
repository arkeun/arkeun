토요일 저녁 8시, 할리갈리를 열두 판째 하는 중이에요. 판이 끝날 때마다 '기록 → 게임 → 승자 → 저장'을 누르는데, 저장할 때마다 '오늘의 승자 현우' 카드가 아래에서 올라와요. 매번 '닫기'를 한 번 더 눌러야 다음 판을 적을 수 있어요.

직접 눌러 본 결과(360px, `r/heavy3.js`·`r/heavy3b.js`, 스크린샷 폴더 `heavy3/`):
- 30판을 실제로 쌓아 봤어요. 끝난 판이 한 줄(44px)로 접혀서 시트 높이가 3,057px로 줄었어요(v34는 8,813px).
- 저장 버튼은 아래에 고정됐어요.
- '앞 판처럼'은 같은 결과를 1번 눌러 넣는 데 잘 동작해요.
- 그래도 한 판을 적는 데 탭 4번과 스크롤 2번이 들어요. 저장 카드까지 닫으면 탭 5번이에요.

## 새로 찾은 것

### 1. 저장할 때마다 '저장 뒤 한 장' 카드가 떠요 (A, 기준 6)
- 화면: heavy3/360-a4-saved-0.png, 360-d1-savedcard.png.
- 근거: 한 판씩 저장하면 30판에 카드 30장이 떠요. 매번 '닫기'를 눌러야 해서 하루에 30번을 더 눌러요. 카드 숫자도 저장할 때마다 바뀌어요('오늘의 승자 현우' → '오늘의 승자 에릭'). 그때마다 가장 큰 초록 버튼이 '단톡방에 공유'예요.
- 비교: 토스는 송금할 때마다 완료 화면을 크게 띄우지 않아요. 같은 곳으로 연달아 보내면 짧은 알림만 보여줘요.
- 고칠 방법: 카드는 그날 처음 저장할 때만 띄워요. 두 번째부터는 아래 토스트 '저장했어요 · 되돌리기'(5초)만 보여줘요. 하루 전체를 공유하는 건 '그날 결과' 시트의 '공유' 버튼이 맡아요.

### 2. '버리기'가 저장 버튼 바로 옆에 붙어 있고, 확인 창이 화면 밖에 떠요 (A, 기준 3)
- 화면: heavy3/360-h1-discard-tap.png.
- 근거: 고정된 아래 줄이 '15판 저장하기 | 버리기'예요. 버리기를 누르면 확인 상자('적던 기록을 버릴까요?')가 시트 맨 아래 y 2,085px에 생겨요. 화면에는 아무 변화가 없어서 한 번 더 누르게 되고, 그러다 15판을 날리기 쉬워요.
- 고칠 방법: 아래 줄에서 버리기를 빼고 '저장하기' 하나만 둬요. 버리기는 시트 제목 줄의 ⋯ 안에 '적던 기록 버리기'로 넣어요. 확인은 화면 가운데 대화상자로 띄워요('15판 적은 걸 버릴까요?' / 버리기 · 취소).

### 3. 같은 날 같은 게임이 두 줄로 나뉘고, 합계는 저장 카드에만 있어요 (B, 기준 1·2)
- 화면: heavy3/360-d2-home.png, 360-e1-day.png.
- 근거: 24일 블록에 '스플렌더 2판 · 현우 1승 · 에릭 1승…'과 '스플렌더 32판 · 에릭 20승'이 따로 나와요. 저장 카드에는 '에릭 21승 · 현우 13승'이라고 나와서, 하루 합계가 홈과 '그날 결과' 어디에도 없어요.
- 고칠 방법: '그날 결과' 시트 맨 위에 저장 카드와 같은 줄을 둬요('오늘 에릭 21승 · 현우 13승'). 기록한 사람별로 줄을 나누는 결정은 그대로 두고, 친구 줄은 '현우님이 남긴 2판'처럼 아래에 붙여요.

### 4. 모임 순위가 판 수로 세져서, 하루 몰아서 한 짧은 게임이 순위를 정해요 (B, 기준 4·7)
- 화면: heavy3/360-j3-grp-rank.png.
- 근거: '전체' 순위가 '11승 / 26판 · 42%'처럼 판마다 1승으로 세요. 동훈네처럼 할리갈리를 하루 40판 하면, 2시간짜리 게임 1판보다 그날 할리갈리가 40배 무겁게 들어가요.
- 고칠 방법: '전체' 순위에서는 같은 날 같은 게임을 1번으로 셉니다. 그날 그 게임에서 가장 많이 이긴 사람을 1승으로 쳐요. 순위 위에 '하루에 여러 판 한 게임은 그날 1위만 세요'라는 안내를 한 줄 둬요. 판마다 센 순위는 게임 칩을 골랐을 때만 보여줘요.

### 5. '그날 결과'가 1번째 판부터 보여서, 방금 적은 판을 보려면 더 눌러야 해요 (B, 기준 6)
- 화면: heavy3/360-e1-day.png.
- 근거: 32판이면 '1번째~5번째'만 보이고 '다음 판 더 보기'를 2번 눌러야 32번째가 나와요. 판마다 적는 사람이 확인하고 싶은 건 방금 적은 판이에요.
- 고칠 방법: 판이 10판이 넘으면 마지막 5판(28~32번째)을 먼저 보여줘요. 위에 '앞 판 더 보기'를 둬서 순서는 1→32를 유지해요.

### 6. 고정된 저장 줄 아래로 내용이 비쳐요 (C, 기준 5)
- 화면: heavy3/360-h1-discard-tap.png, 360-c2-folded-mid.png.
- 근거: 저장 줄 아래끝이 760px인데 화면은 780px이라, 20px 틈 사이로 '이름으로 찾기'와 '23번째 판'이 보여요.
- 고칠 방법: `.sheet-foot.stick`의 아래 여백을 시트 padding에 맞춰 0으로 해요(`margin-bottom: calc(-1 * 시트 아래 padding)`). 360px에서 저장 줄 아래끝이 화면 끝과 같아야 해요.

### 7. 혼자 한 판을 저장하면 '지난번처럼: · 스플렌더'가 돼요 (C, 기준 1)
- 화면: heavy3/360-i3-solo-saved.png.
- 근거: 사람이 비어 있어서 줄이 점(·)으로 시작해요.
- 고칠 방법: 사람이 없으면 '지난번처럼: 혼자 · 스플렌더'라고 써요.

## 1·2회차 미반영
- 시트를 열면 게임 타일이 화면 밖에 있어요(360px에서 y 739~817). 30판을 쌓는 동안 매번 한 번씩 내려야 했어요.
- 새 판을 추가해도 화면이 따라가지 않아요. 새 판의 승자 칩이 942px → 2,151px로 판마다 132px씩 더 아래에 생겨요.
- 게임 단위에서 사람을 빼면 지난 판의 승리 기록까지 지워져요(`toggleGamePerson` 그대로).
- 저장 뒤 되돌리기가 없어요('되돌리기' 문구 0곳).
- '그날 결과'에서 판 하나를 눌러 고칠 수 없어요(`.rline`에 누르는 동작이 없음).

## 잘 된 점
- 끝난 판 한 줄 접기 덕분에 30판 시트가 3,057px로 줄었어요(v34의 3분의 1). 고정된 '30판 저장하기'는 엄지가 바로 닿아요.
- '앞 판처럼'은 같은 팀이 연달아 이기는 게임에서 1번 누르면 끝나요.
- 혼자 한 판은 '88점 · 첫 기록' 카드가 담백하고 보기 좋아요.
