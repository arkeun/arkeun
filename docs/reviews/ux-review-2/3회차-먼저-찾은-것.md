다섯 명이 v45에 새로 들어간 화면(저장 뒤 한 장, 혼자 했어요, 앞 판처럼, 날짜별·순위, 빈 홈, 1년 전 오늘)을 직접 눌러 봤어요. review-log에 이미 있는 건 뺐어요. 괄호 안은 찾은 사람 수, [ ]는 기준 번호예요. 원문은 같은 폴더 *-r3.md에 있어요.

## 우리가 먼저 찾은 것 (17개)
### 저장 뒤 한 장
1. **그날 판을 전부 합쳐서 세요.** (2명) [3·7] 가족 팬데믹을 저장했는데 "현우·에릭 공동 1위"가 떠요. 현우는 아침 모임에만 있던 사람이고, 실제로 이긴 서윤은 빠져요. 커플 카드를 공유해도 모임 사람들이 찍혀요.
   → 방금 저장한 판만 세요. 이긴 사람은 숫자 없이 모두 보여 줘요.
2. **저장할 때마다 떠요.** (1명) [6] 하루 30판이면 "닫기"를 30번 더 눌러야 해요.
   → 카드는 그날 처음 저장할 때만 띄워요. 두 번째부터는 "저장했어요 · 되돌리기" 토스트(5초)만 보여 줘요.
3. **공유하면 다른 카드가 나가요.** (1명) [7] 분홍 커플 카드에서 공유를 누르면 진녹색 "하루 요약" 글자 카드가 나가요.
   → 보고 있는 카드를 그대로 이미지로 내보내요.
4. **협력 결과와 받을 사람을 반영하지 않아요.** (1명) [1·7] 다 같이 이긴 날도 "저장했어요"만 나와요. 같이 한 사람이 앱이 없는 아이들뿐인데도 "단톡방에 공유"가 나와요.
   → 이긴 날은 "우리가 이겼어요!"로 보여 줘요. 앱 친구가 없으면 "사진으로 저장"으로 바꿔요.
5. **숫자가 서로 달라요.** (1명) [2] "둘이 함께한 413판째"인데 커플 머리는 402판이에요. 바로 아래 D+413과 겹쳐서 오류처럼 보여요.
   → 같은 기준으로 맞추거나 카드에서 숫자를 빼요.
6. **방금 적은 기록으로 가는 길이 없어요.** (1명) [6] 보관함에서 기록하면 닫은 뒤 빈 선반만 보여요.
   → "닫기"를 "기록장에서 보기"로 바꿔요.

### 기록 시트
7. **"버리기"가 저장 버튼 바로 옆에 있어요.** (3명) [3·6] 누르면 확인창이 화면 밖(y 1,500~2,000)에 떠서 아무 반응이 없는 것처럼 보여요. 고치기 화면의 빨간 "이 날 지우기"도 같아요.
   → 고정 줄에는 "N판 저장하기"만 둬요. 버리기와 지우기는 ⋯ 안으로 옮기고, 확인은 화면 가운데 팝업으로 띄워요.
8. **"혼자 했어요"가 67×18px 링크예요.** (2명) [3·6] 한 번 누르면 고른 사람이 다 빠지고 되돌릴 수 없어요.
   → "자주 같이 한" 칩 줄 맨 앞에 44px "혼자" 칩을 둬요. 다시 누르면 고른 사람이 돌아와요.
9. **고정 저장 줄 아래로 내용이 비쳐요.** (2명) [5] 360px에서 20px 틈이 생겨요.
10. **다시 열면 게임 칸이 "아직 기록한 게임이 없어요"예요.** (1명) [1·6] 사람을 고르기 전에만 쓸 수 있는 탭이 첫 탭으로 열려요.
   → 사람을 고르기 전에는 "최근" 탭으로 시작해요.

### 홈·빈 화면
11. **혼자 한 판을 저장하면 홈에 "지난번처럼: · 스플렌더"가 떠요.** (3명) [1]
   → 사람이 없으면 "지난번처럼: 혼자 · 스플렌더"로 써요.
12. **빈 홈에 같은 일을 하는 초록 버튼이 둘이에요.** "오늘 기록하기"와 "첫 기록 남기기"예요. 첫 안내도 "BGG를 쓰셨다면…"이라 BGG를 모르는 사람은 막혀요. (3명) [1·5]
   → 가운데 버튼을 지우고 "위 '오늘 기록하기'로 첫 판을 적어 보세요"로 바꿔요. BGG 가져오기는 그 아래 작은 링크로 둬요.
13. **빈 화면 문구가 틀려요.** (2명) [1·2]
   - 0판인데 "오늘 처음 기록했어요", "2026 결산 올해 0판"이 나와요.
   - 빈 모임 탭에 "'' 모임이 없어요."가 나와요(검색어가 비어 있는 버그).
   - 닉네임을 정하기 전에는 제목이 "나 기록장", 탭 이름이 "나"예요.
   → 0판일 땐 통계·결산을 숨겨요. 모임 탭은 "아직 모임이 없어요"로 고쳐요. 처음에 이름 한 칸을 받아요.
14. **1년 전 오늘의 "공유"가 눌리지 않아요.** (1명) [6] 누르면 사진 확대가 떠요. 공유 카드에도 1년 전이라는 표시가 없어요.
   → 사진 위에 44px 공유 아이콘을 두고, 카드에 "1년 전 오늘 · 2025년 11월 24일"을 넣어요.

### 모임 순위·사람
15. **순위 한 줄에 숫자가 세 개예요.** "11승 / 26판 · 42%"인데, 순서는 %로 매겨서 10승이 6위, 9승이 3위예요. 300명 모임에서는 내 줄도 안 보여요. (3명) [1·2·4]
   → 오른쪽에 "42%"만 두고, 머리에 "이긴 비율 순 · 5판 이상"을 적어요. 맨 아래에 내 줄을 고정해요.
16. **앱 없는 아이의 사람 화면이 어른 친구 화면과 같아요.** (1명) [7] "도윤님이 앱에 가입했나요? @아이디 연결"과 초대가 화면 절반을 차지하고, "스플렌더 0:0"도 보여요.
   → 가입·연결은 ⋯ 안으로 옮기고, 0:0 줄은 숨겨요.
17. **모임 기록 탭에 세그먼트가 두 줄 겹쳐요.** "약속|대화|기록|멤버" 아래에 "날짜별|순위"가 있어요. (1명) [5]
   → 아래 줄은 글자 탭이나 오른쪽 위 전환 아이콘으로 바꿔요.
