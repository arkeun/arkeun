# 검토 기준 (2026-11-23, 모든 검토 담당이 화면마다 확인)

에릭님이 말하기 전에 먼저 찾기. 매 검토마다 에릭님이 아직 말 안 한 문제 최소 10개, 보고는 "에릭님이 말한 것 / 우리가 먼저 찾은 것"으로 나눔.

1. 처음 보는 사람도 바로 알아듣나: 만든 사람만 아는 말 찾기. 토스·카카오·왓챠피디아 같은 실제 앱이라면 이렇게 쓸지 비교.
2. 이 숫자가 꼭 필요한가: 시간, 판 수, 개수처럼 쓸데없는 숫자(숫자는 통계 탭에만).
3. 기분 나쁜 게 눈앞에 있나: 빼기·지우기·패배·빨강.
4. 수백 개가 되면 어떻게 되나: 모임 300, 하루 30판, 보관함 500, 질문 수백 개.
5. 화면이 하는 일이 하나인가.
6. 기록 쓰고 보기가 더 빨라졌나: 누르는 횟수 세기.
7. "나"가 아니라 그 사람답게 보이나: 닉네임·커플·모임.

에릭님이 새로 지적하면 기준을 하나씩 늘림.

# 홈 검토 기록 (구성·디자인·초안 AI)

형식: 문제 → 누가 뭐라고 했나 → 결정

## 1회차: 시안 3가지 검토
- **홈 맨 위 숫자 줄(이번 주 33판·6주 연속·새 댓글 15)**
  → 구성: 소식 위에 통계까지 얹으면 화면 목적이 두 개가 됨 / 초안: 동의
  → 결정: 홈에서 뺌. 숫자는 에릭 탭, 새 댓글은 🔔로.
- **친구 소식 전체를 최신순으로 보여주는 홈**
  → 구성: 모임이 수백 개면 남의 기록에 덮이고, 출시 초엔 앱 쓰는 친구가 없어 텅 빔 / 초안: 동의, 범위를 좁히자
  → 결정: 에릭이 들어간 기록 + 에릭 모임 기록만, 위에 모임 칩 줄.
- **보관함이 하단 탭에서 사라짐**
  → 구성: 수백 개를 자주 훑는 곳이라 게임 탭 안에 둠 / 초안: 동의, "오래 안 한 순"·"오늘 뭐 할까"도 거기로
  → 결정: 게임 탭 = 검색 + 보관함 · 즐겨찾기 · 해본 게임.
- **3번 시안의 "오늘 목요일, 지난번처럼"**
  → 구성: 좋은 아이디어라 살림 / 초안: 우선순위를 정함
  → 결정: 홈 맨 위 조건부 1장(이어 적던 기록 > 타이머 > 모임 요일).
- **친구가 에릭을 넣은 기록 알림**
  → 초안: 따로 알림함 없이 피드 카드로 / 구성: 알림은 사용자가 정한 규칙이니 🔔도 같이
  → 결정: 카드 + 🔔 둘 다.
- **"내 기록에서 빼기" 문구**
  → 구성: 화면에 '나' 쓰지 말라는 규칙에 걸림
  → 결정: "에릭 기록에 들어왔어요" / "빼기".
- **기록 버튼 모양**
  → 디자인: 볼록 튀어나온 + 대신 평평한 가운데 탭 / 구성: 위치는 가운데 그대로
  → 결정: 가운데 평평한 탭, 초록 아이콘.

## 2회차: 에릭님 "기록 앱이니까 쉽게 쓰고 쉽게 확인하는 게 메인"
- **홈이 소식 피드라 기록 앱의 중심이 흐려짐**
  → 구성: 홈을 에릭 기록장으로 바꾸자 / 초안·디자인: 동의
  → 결정: 홈 = 에릭이 들어간 기록만 하루 단위 최신순. 친구가 남긴 건 "현우님이 남김"으로 섞음. 에릭이 빠진 모임 기록은 모임 탭으로. 모임 칩 줄 없앰.
- **쉽게 쓰기**
  → 구성: 맨 위 입력 줄 항상 / 디자인: 폭 꽉 찬 초록 버튼 하나, 홈에서 유일한 초록 채움이라 시선이 여기로만 감
  → 결정: "오늘 기록하기" 버튼, 상태에 따라 같은 자리에서 "윙스팬 32분째 · 이어 적기" 등으로 바뀜. 아래 "지난번처럼" 한 줄. 가운데 기록 탭도 다른 화면용으로 유지.
- **수천 판에서 쉽게 찾기**
  → 구성: 검색 + 월 이동, 단 달력 모양은 금지(에릭님이 거절) / 디자인: 월 버튼을 따로 두지 말고 화면 위에 붙는 월 머리줄 "11월 ▾"을 누르게
  → 결정: 버튼 아래 검색창 한 줄, 월 머리줄("11월 · 23판 · 9일")을 누르면 월 목록.
- **사진을 크게 보여줄지**
  → 디자인(처음): 피드에서 크게 / 구성: 기록 확인이 먼저라 반대
  → 결정: 카드 오른쪽 위 작은 썸네일 1장 + "+N", 크게는 하루 상세에서.

## 3회차: 나머지 탭과 보관함
- **기록 확인 화면이 여기저기 흩어질 위험**(게임 상세의 "12판", 친구 전적, 모임 기록)
  → 구성: 모두 홈 기록장에 필터만 건 화면으로 통일, 검색창 결과도 같음
  → 초안: 게임 상세 "N판 · 기록 보기", 사람 전적 "같이 한 기록 보기"를 홈 기록장 검색으로 열게 함
  → 결정: 반영.
- **보관함을 더 예쁘고 감각 있게(에릭님 요청)**
  → 구성: 게임 탭 안 세그먼트로는 묻힘. 하단 탭 이름을 "보관함"으로 바꾸고 열면 바로 표지 격자가 나오게. 정렬(최근 산·많이 한·오래 안 한·이름), 격자/목록, 상태 걸러보기, 위에 "331개 · 이번 달 2개 들임" 한 줄만
  → 디자인: 보관함 화면을 우선해서 시각안 작업 중
  → 결정: 탭 = 홈 · 보관함 · 기록 · 모임 · 에릭. 반영.
- **보관함 보기 방식**
  → 디자인: 박스를 실제 비율로 세운 "선반 보기"가 기본, 수백 개 훑기용 "쌓아 보기"(한 화면 25개)가 목록 보기를 대신. 빌려줌은 메모지 꼬리표("태호"), 확장은 박스 뒤 겹친 박스, 팔았음은 필터로만, 이름순일 때 ㄱㄴㄷ 빠른 이동, 빈 보관함엔 빈 선반의 캐릭터
  → 구성: 동의. 검색창을 누르면 별도 검색 화면이 열려 선반과 섞이지 않음
  → 결정: 위 방향으로 초안 반영.
- **선반 연출 범위와 검색**
  → 디자인: 선반 판은 "보관함"에만, 즐겨찾기·해본 게임은 판 없는 격자(보관함이 특별해 보이게). 검색은 "보관함에 있는 게임"이 먼저, 아래 "전체 게임"
  → 구성: 동의. 보관함 안 검색칸을 따로 두지 않아도 됨
  → 결정: 반영.
- **글꼴**
  → 디자인: Pretendard 하나로 통일 / 초안: 웹 초안 페이지는 구글 폰트만 불러올 수 있어 Pretendard를 못 씀
  → 결정: 웹 초안은 Noto Sans KR(기기에 Pretendard가 있으면 그걸 씀), 앱으로 만들 때 Pretendard.

## 5회차: 실사용자 입장 점검 (사용자 역할 AI 추가, 에릭님 요청)
전체 내용: persona-review.md (커플·모임장·기록러·평가러·수집가 다섯 사람, 비교 앱: BG Stats·BGG·소모임·문토·Meetup·비트윈·Letterboxd·Untappd)

  → 결정(제안): 커플 탭 = 추억 · 기록 · 전적, 첫 탭 추억. 프로필 사진 허용. 구성·디자인·초안에 전달.
- **모임에 약속·소개·운영 권한이 없음**
  → 사용자 역할: 모임의 가장 큰 일이 "다음에 언제 해?"인데 앱 밖(카톡)으로 나감
  → 결정(제안): 모임 탭 = 약속 · 대화 · 기록 · 멤버(순위는 기록 안), 소개 화면, 모임장 공지·승인·내보내기, 상단 버튼 ⋯로.

- **"내 전적·내 평가·내 보관함·내 캐릭터"** 문구 남아 있음 → 닉네임으로.
- **대화방, 동네 모임 찾기**는 서버·개인정보 범위가 커서 에릭님 결정으로 올림.

## 6회차: 사용자 관점 담당 의견에 대한 구조 판단 (자세한 내용: persona-review.md)
- **커플 화면이 성적표 같고 사진이 없음** → 사용자 관점: 탭 추억 · 기록 · 전적 → 구성: 동의. 맨 위는 대표 사진 + D+ + 승수 한 줄.
- **모임에 약속·대화·소개·관리가 없음** → 사용자 관점: 탭 약속 · 대화 · 기록 · 멤버 → 구성: 동의. 대화방은 에릭님 결정 전까지 약속마다 댓글로 시작(탭 3개). 소개는 이름 누르면, 관리 버튼은 ⋯ 하나로.

- **에릭 탭** → 사용자 관점: 통계 · 게임 · 사람 · 평가 → 구성: "게임"은 보관함 "해본 게임"과 겹쳐서 빼고 통계 · 사람 · 평가. 사진·캐릭터는 머리, 설정은 톱니, 가져오기·내보내기는 설정 안.
- **모임 찾기 입구** → 구성: 하면 모임 탭 맨 위. 하단 탭은 늘리지 않음.
