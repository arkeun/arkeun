보드게임 플레이 기록 앱 웹 초안을 실제 이용자 관점에서 검토한 결과, 앱의 완성도와 사용성을 높이기 위해 **가장 먼저 고쳐야 할 중요한 점 7가지**를 중요도 순서대로 정리해 드립니다.

---

### 1. [기록 입력 화면] 모바일 가상 키보드 영역과 하단 고정 버튼 겹침 현상
* **무엇이 문제인가:** `PlaySheet` 컴포넌트 하단의 `sheet-foot stick` 영역(`저장하기` 버튼 등)이 `position: sticky` 또는 고정 레이아웃으로 처리되어 있습니다. 실제 모바일 환경(아이폰 등)에서 인풋창을 터치해 가상 키보드가 올라오면, 하단 고정 버튼이 키보드와 겹치거나 화면 중간에 붕 떠서 입력 중인 폼을 가려버리는 치명적인 흐름 방해(코드상 명확한 스크롤 컨테이너 패딩 누락)가 발생합니다.
* **어떻게 바꾸면 좋을지:** 시트 내부의 마지막 콘텐츠 영역 아래에 키보드 높이만큼의 여백(`padding-bottom`)을 동적으로 확보하거나, 모바일 환경에서 시트 전체 스크롤 영역이 키보드 위로 안전하게 리사이징되도록 CSS 구조를 수정해주세요.

### 2. [기록 입력 화면 / 1단계] '혼자' 버튼과 인원 선택 상태의 시각적 분리 미흡
* **무엇이 문제인가:** `PlaySheet`의 1단계(누구랑 했어요?) 상단에 '혼자' 버튼(`solochip`)이 배치되어 있으나, 다른 친구 칩들과 동일한 행 혹은 애매한 위치에 있어 사용자가 혼자 플레이할 때와 여럿이 플레이할 때의 모드 전환을 직관적으로 인지하기 어렵습니다. 코드 상에서도 `people.length === 0`일 때의 상태 변화가 직관적인 토글 피드백을 주지 못합니다.
* **어떻게 바꾸면 좋을지:** '혼자하기 / 여럿이 하기'를 상단에 명확한 세그먼트 컨트롤 형태로 분리하고, '혼자'를 선택했을 때는 아래 친구 선택 영역이 자연스럽게 비활성화(Dimmed)되도록 시각적 계층 구조를 개선해주세요.

### 3. [보관함 화면] 상단 탭/필터 영역과 검색바의 고정(Sticky) 부재로 인한 탐색 피로도
* **무엇이 문제인가:** 수백 개의 게임 보관함(`Shelf` 컴포넌트)을 스크롤하여 내려갈 때, 상단의 검색바, [보관함 / 사고 싶은 / 해본 게임] 탭, 그리고 정렬/필터(슬라이더) 버튼이 함께 스크롤되어 사라집니다. 목록이 길어질수록 다시 필터를 바꾸거나 검색하려면 맨 위로 스크롤을 올려야 하는 불편함이 있습니다.
* **어떻게 바꾸면 좋을지:** 상단 검색바와 탭 영역에 `position: sticky; top: 0; z-index: ...`를 적용하여, 스크롤을 내려도 사용자가 언제든지 보관함 탭이나 필터를 조작할 수 있도록 변경해주세요.

### 4. [홈 기록장 화면] 검색 결과와 일반 피드(날짜별 그룹) 간의 전환 가시성 부족
* **무엇이 문제인가:** 홈 화면에서 상단 검색창(`hq`)에 검색어를 입력하면 리스트가 필터링되지만, 사용자가 "현재 검색 결과만 보고 있다"는 사실을 인지하기 어렵습니다. 안내 문구가 작고 하단에 애매하게 위치하여, 사용자가 전체 기록을 보는 것인지 검색된 결과인지 헷갈릴 수 있습니다.
* **어떻게 바꾸면 좋을지:** 검색어가 입력된 상태에서는 화면 상단에 눈에 띄는 배경색(예: 연한 회색/포인트 컬러 밴드)과 함께 **"'OO' 검색 결과 N개 (전체보기로 돌아가기)"** 형태의 명확한 상태바를 고정 노출해주세요.

### 5. [게임 상세 화면] 탭 전환 시 스크롤 위치 초기화 문제
* **무엇이 문제인가:** `Detail` 컴포넌트에서 [정보 / 평가 / 질문] 탭을 전환할 때, 페이지 전체의 스크롤 위치가 유지된 채 내부 컨텐츠만 바뀌어 사용자가 보던 위치를 놓치거나 엉뚱한 위치를 보게 될 수 있습니다.
* **어떻게 바꾸면 좋을지:** 탭을 누르는 순간 화면 상단(혹은 탭 바 위치)으로 부드럽게 스크롤이 이동(`window.scrollTo({ top: ..., behavior: 'smooth' })`)하도록 처리하여 탭 전환의 맥락을 유지해 주세요.

### 6. [기록 입력 화면 / 2단계] 게임 추가 후 판(Round) 확장 UI의 복잡성
* **무엇이 문제인가:** 여러 판을 기록할 때 각 판마다 승자, 순위, 확장, 점수 입력 영역이 펼쳐지면서 화면이 불필요하게 길어집니다. 특히 점수를 입력하면 자동으로 승자가 지정되는 로직(`prefill`)이 있으나, 사용자가 직접 수동으로 바꿨을 때의 상태(`autoPick`)와 충돌이 일어나 혼란을 줄 수 있습니다.
* **어떻게 바꾸면 좋을지:** 기본적으로 각 판은 한 줄 요약 형태로 접혀 있게(`folded`) 만들고, 상세 점수나 메모를 입력할 때만 아코디언처럼 펼쳐지도록 기본 인터랙션을 수정해주세요. 

### 7. [모임 화면] 모임 목록 내 '다음 약속' 정보의 가독성 개선
* **무엇이 문제인가:** `GroupsList` 화면에서 각 모임 셀에 다음 약속 정보가 텍스트로 작게 포함되어 있으나, 날짜와 장소, 그리고 내가 참석하는지 여부('가요/못 가요')가 한눈에 들어오지 않습니다. 수십 개의 모임을 관리하는 규모를 가정할 때 어떤 모임에 다가오는 약속이 있는지 직관적으로 파악하기 어렵습니다.
* **어떻게 바꾸면 좋을지:** 다가오는 약속이 있는 모임의 경우, 카드 우측이나 하단에 별도의 시각적 뱃지(예: 🟢 D-2 오늘 모임, 🔵 참석 확정 등)를 달아주어 사용자의 눈길을 자연스럽게 약속 정보로 유도해주세요.
