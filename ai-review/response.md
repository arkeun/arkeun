보드게임 기록 앱 초안을 이용자 입장에서 꼼꼼히 살펴보았습니다. 핵심 기능에 충실하면서도 '사람 심리(승부욕, 자랑, 추억, 다정함)'를 더 자극할 수 있도록, 중요한 순서대로 개선 의견을 드립니다.

---

### 1. 문구 개선 제안 (최대 25개)

1. 「12 : 3」 → 「에릭 12승 · 지민 3승 (총 15판)」 (사람×게임 맞대결 화면, 숫자만 달렁 있으면 밋밋하고 게임 결과라는 직관성이 떨어짐)
2. 「우리가 짐」 → 「아쉽게 패배... 다음엔 꼭 잡기!」 (공유 카드 화면, 진 기록을 너무 건조하게 표현하면 공유하고 싶지 않음)
3. 「에릭 210 : 192 지민」 → 「함께 쌓은 412판 · 에릭 210승 VS 지민 192승」 (커플 화면, 다정한 관계 속에서 가벼운 라이벌 의식을 유쾌하게 포장)
4. 「지민님이 새로 찜한 게임 2개」 → 「지민님이 몰래 찜한 게임 2개 👀 (같이 해볼까요?)」 (커플 화면, 설렘과 기대감을 주는 문구로 변경)
5. 「다음 플레이 ○」 → 「다음 데이트 날짜: ○ (기다려지는 중 ♥)」 (커플 화면, 단순한 일정보다 감정을 건드리는 표현)
6. 「게임별 맞대결」 → 「피할 수 없는 승부처 (게임별 맞대결)」 (사람 전적 화면, 경쟁의 재미를 살림)
7. 「협력 게임 승률 47%」 → 「힘을 합쳐 탈출 성공률 47%」 (사람 전적 화면, 협력 게임의 특성을 살려 '함께 싸운다'는 느낌 부여)
8. 「지민님이 9번 더 이겼어요」 → 「지민님에게 바짝 추격당하는 중 🏃‍♂️」 (사람×게임 맞대결 화면, 지고 있을 때의 유쾌한 긴장감 유발)
9. 「지민님과 아직 안 해본 ○ 게임」 → 「아직 둘이서 안 해본 숨은 보석 같은 게임 💎」 (사람 전적 화면, 호기심 자극)
10. 「올해 782판」 → 「올해 벌써 782판이나 달렸어요! 🎲」 (MY 화면, 기록하는 수고에 대한 뿌듯함과 보상 제공)
11. 「35% 승률」 → 「승률 35% (꺾이지 않는 마음 🔥)」 (MY 화면, 승률이 낮아도 기죽지 않고 웃어넘길 수 있는 위트 추가)
12. 「오늘 기록하기」 → 「오늘 어떤 승부가 펼쳐질까요? 기록 남기기」 (홈 화면, 단순 행위보다 기대를 유발)
13. 「아직 안 해본 게임이에요」 → 「운명의 게임을 기다리는 중 (아직 안 해봄)」 (게임 상세 화면, 친근한 톤)
14. 「제일 많이 같이 한 사람 ○」 → 「가장 손발이 잘 맞는 영혼의 단짝 🤝 ○」 (게임 상세 화면, 단순 통계 이상의 의미 부여)
15. 「오늘의 승자 에릭 10승」 → 「오늘의 보드게임 주인공은 '에릭' 👑 (10승 달성!)」 (공유 카드 화면, 자랑하고 싶은 심리 극대화)
16. 「플레이 기록 CSV로 저장」 → 「나만의 보드게임 역사 백업하기 (CSV)」 (설정 화면, 단순 기능 설명보다 가치 부여)
17. 「예시 기록·보관함·평가 지우기」 → 「튜토리얼 예시 데이터 깔끔하게 지우기」 (설정 화면, 명확하고 친절한 안내)
18. 「탈퇴하면 기록·보관함·평가가 모두 지워져요.」 → 「정말 떠나시게요? 모든 추억과 기록이 사라져요 😢」 (설정 화면, 이탈 방지 및 감성적 접근)
19. 「사진·영상 (보드 상황)」 → 「생생한 현장 포착! 그날의 순간 남기기 📸」 (질문/리뷰 화면, 기록의 즐거움 강조)
20. 「비슷한 질문 ○개를 찾았어요.」 → 「앗, 먼저 물어본 사람이 있어요! 미리 확인해 볼까요?」 (Q&A 화면, 챗봇처럼 친근한 대화형 말투)
21. 「다른 사람이 먼저 추가한 게임이에요.」 → 「누군가 먼저 등록해 둔 소중한 게임이에요 ✨」 (게임 추가 화면, 커뮤니티 기여에 대한 존중)
22. 「바코드로 담기」 → 「찰칵! 바코드로 순식간에 보관함에 넣기 📦」 (보관함 화면, 행동 유도형 문구)
23. 「아직 찜한 게임이 없어요.」 → 「하고 싶은 게임을 찜해두고 다음 데이트를 준비해 보세요!」 (커플 화면, 행동 가이드 제공)
24. 「이름이나 @아이디」 → 「함께 판을 벌인 친구를 찾아보세요 (이름 또는 @아이디)」 (기록 입력 화면, 보드게임 은어 활용)
25. 「공유하기」 → 「이 완벽한 하루를 친구들에게 자랑하기 뽐내기 🤩」 (공유 카드 화면, 자랑 심리 자극)

### 2. 디자인 심리 장치 제안 (화면당 1~2개, 총 7개)

1. **홈 화면 (`01-홈.png`)**: 
   - *장치*: **'연승/연패 배지' 및 '첫 승 기념' 연출**
   - *이유*: 단순한 승패 나열 대신, "3연승 중!" 이나 "이 게임 첫 승리!" 같은 순간에 폭죽 이펙트나 왕관 마크를 미세하게 주어 기록하는 맛(도파민)을 살려주세요.
2. **사람 전적 화면 (`p2-person.png`)**: 
   - *장치*: **'나만의 라이벌' 선언 카드**
   - *이유*: 나와 전적이 가장 팽팽한 사람(예: 380승 359패)에게 자동으로 "공식 라이벌 🔥" 타이틀을 붙여주고, 상대를 이겼을 때 특별한 문구가 뜨게 해 경쟁 심리와 재미를 동시에 자극하세요.
3. **사람 × 게임 맞대결 화면 (`p3-pvg.png`)**: 
   - *장치*: **'설욕전' 또는 '천적' 관계 시각화**
   - *이유*: 특정 사람에게 유독 약할 때("지민님에게 승률 20% · 복수의 칼을 갈아보세요 🗡️") 유쾌한 도장이나 심볼을 넣어 다음 판에 대한 투지를 북돋아 주세요.
4. **공유 카드 화면 (`share-night.png`)**: 
   - *장치*: **'오늘의 MVP' 캐릭터 일러스트 강조**
   - *이유*: 승리한 사람의 캐릭터가 왕관을 쓰고 당당하게 서 있는 모습을 카드 상단에 크게 배치해, 인스타 스토리에 올렸을 때 "나 오늘 이겼다!"를 멋지게 자랑하고 싶게 만들어 주세요.
5. **커플 화면 (`07-커플.png`)**: 
   - *장치*: **'추억의 오늘 (1년 전/2년 전)' 타임캡슐 카드**
   - *이유*: "정확히 2년 전 오늘, 이 자리에서 아줄을 처음 했어요 ♥" 같은 과거 기록을 툭 던져주어 둘만의 다정한 추억을 상기시키고 다시 보드게임을 잡게 만드세요.
6. **MY 화면 (`05-MY.png`)**: 
   - *장치*: **'올해의 보드게임 왕국 요약' (연말 결산 미리보기)**
   - *이유*: 딱딱한 통계 숫자(2653판, 35%) 대신, "올해 에릭님은 스플렌더의 지배자였어요!" 같은 스토리텔링형 카드로 내 게임 인생을 돌아보는 뿌듯함을 주세요.
7. **기록 입력 완료 시점 (`SavedSheet`)**: 
   - *장치*: **'기록 보상 깜짝 메시지'**
   - *이유*: 귀찮음을 무릅쓰고 기록을 마쳤을 때, "벌써 이 게임 30판째 기록이네요! 고생했어요 👏" 같은 소소한 축하 메시지를 띄워 기록하는 수고에 보상을 줍니다.

### 3. 피해야 할 점 (경쟁 스트레스 및 부담감 완화)

- **지친 패배자에 대한 배려 부족**: 
  - 현재 전적 화면이나 공유 카드에서 진 판을 너무 차갑게("우리가 짐", "12 : 3") 강조하면, 진 사람이 앱을 켤 때마다 스트레스를 받거나 기록 입력을 꺼리게 됩니다. 패배한 기록에는 "다음 판은 전략을 바궈봐요!", "다음에 갚아주기 😎" 같은 유쾌한 패배의 변명거리를 붙여주어 **승패보다 '같이 놀았다'는 과정 자체에 집중**할 수 있게 분위기를 완화해 주세요.
- **숫자형 통계의 압박감**: 
  - 승률이 30%대로 떨어졌을 때 유저가 기죽지 않도록, 전체 승률 숫자만 크게 보여주기보다는 "협력 게임 승률이 높네요!", "이 사람과 할 때 가장 오래 웃었어요" 같은 정서적 지표를 함께 보여주는 것이 좋습니다.
