# 역할: 상황별 사용자 검토자
다섯 사람이 되어 각자 상황에서 화면이 **그 상황에 맞게 바뀌는지** 봐 주세요.
1) 혼자 하는 준혁(38): 솔로 게임(캐스캐디아 솔로 등)을 점수 위주로 기록. 지금 혼자 기록에 '이겼어요/졌어요'와 '닉네임 점수'가 여럿이 할 때와 같은 모양으로 나와요(eric-phone-record, 15-solo). 혼자일 때 맞는 말·모양(예: 성공/실패, 내 점수 하나, 최고 점수와 비교)은?
2) 커플 지민(29): 둘이서만 함. 기록 시트·홈 카드·저장 화면이 둘일 때 맞게 바뀌는지.
3) 모임 기록 담당 태호(36): 80명 동호회, 하루 수십 판, 테이블마다 사람 다름. 빠르게 적을 수 있는지, 사람이 많을 때 칩이 넘치는지.
4) 모임 일반 멤버 소연(31): 남이 적은 기록을 주로 봄. 알림·홈·하루 상세에서 '내 판'을 바로 찾는지.
5) 처음 깐 다은(26): 첫 기록에서 막히는 곳.
사람마다 "지금 화면이 이 상황에 안 맞는 곳 / 어떻게 바뀌어야 하는지"를 적어 주세요. 공통 조건의 12개는 다섯 명을 합쳐서 세요.

## 앱 소개 (꼭 읽고 판단해 주세요)
- 한국 사람이 쓰는 보드게임 **기록 앱**이에요. 핵심은 "누구와 어떤 게임을 했고 누가 이겼는지"를 쉽게 쓰고 쉽게 다시 보는 것.
- 하단 탭: 홈(내 기록장) · 보관함(가진 게임) · 기록(가운데, 누르면 기록 시트) · 모임 · {닉네임}(통계·내 정보).
- 기록은 하루 단위로 묶여요. 한 날에 여러 게임·여러 판. 판마다 승자/순위/협력(우리가 이김·짐), 점수·사진·메모는 선택.
- 이용자: 커플(둘이 자주 함), 모임 기록 담당(80명 동호회, 하루 수십 판 적음), 모임 일반 멤버(남이 적은 기록을 봄), 혼자 하는 사람(솔로 게임, 점수 위주), 처음 깐 사람.
- 규모: 기록 수천 판, 모임 수백 개, 보관함 수백 개를 가정해요.
- 정해진 원칙: 화면마다 목적 하나 / "나" 대신 닉네임 / 기록장에는 시간·판 수 통계를 두지 않고 통계 탭에만 / 부정 버튼(빼기·나가기)은 ⋯ 안으로 / 이모지 대신 선 아이콘 / 보관함은 특히 예쁘게(크림 바탕·나무 선반) / ~해요체.
- 지금 상태: 웹 초안(React). 게임 이름 "예시 게임 123"은 아직 실제 데이터가 없어서 넣은 자리 채우기예요(문제로 보지 않아도 돼요).
