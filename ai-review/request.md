[앱 목적과 기준]
보드게임 기록 앱이에요. 누구와 어떤 게임을 했고 누가 이겼는지 쉽게 쓰고 쉽게 다시 보는 게 핵심이에요. 규모는 크게 잡아요: 모임 수백 개, 멤버 수십~수백 명, 기록 수천 판(하루 한 게임 수십 판도), 보관함·찜 수백 개. 기록장에는 시간·"몇 판" 같은 숫자 통계를 두지 않아요(통계 화면에만). 문구는 실제 앱처럼 자연스럽게 써요. 부정 버튼은 ⋯ 안에 둬요. 화면마다 목적은 하나예요. 당신은 의견만 내고, 수정은 Claude가 해요. index.html 은 최신 전체 코드(꾸밈 CSS 생략)예요.

[1부: 지난번 당신의 7개 의견에 대한 Claude의 답. 각 항목에 "동의 / 반대 + 이유"로 짧게 답해 주세요. 코드에서 Claude가 틀렸다면 함수 이름과 동작으로 근거를 대 주세요.]
1. 저장 버튼과 키보드 겹침: 저장 줄은 시트 안에서 position: sticky; bottom: 0 이에요(.sheet-foot.stick). 실제 아이폰에서 확인 후 판단할게요. 코드상 확실한 근거가 있으면 알려 주세요.
2. '혼자' 버튼: PlaySheet 1단계 제목 줄의 solochip 은 이미 켜고 끄는 버튼이에요(aria-pressed, 누르면 사람 모두 빠지고 다시 누르면 전에 고른 사람이 돌아옴). 버튼을 더 나누면 복잡해져서 반대해요.
3. 보관함 검색·정렬이 스크롤 때 사라짐: 동의해요. Shelf 의 .sh-ctl 을 위에 붙일게요.
4. 홈 검색 중 표시: Home 에서 검색창 바로 아래에 "'카탄' 들어간 기록만 보고 있어요 · 전체 보기"가 이미 나와요. 개수는 기록장 숫자 기준 때문에 안 넣어요. 반대해요.
5. 게임 화면 탭 전환 때 위치: 동의해요. 탭을 누를 때 탭 줄이 화면 위로 지나가 있으면 탭 줄로 올릴게요.
6. 판 입력: 판 접기는 이미 있어요(RoundRow 의 folded). 점수 자동 승자(prefill/autoPick)와 손으로 고친 승자가 충돌한다고 했는데, 정확히 어떤 순서로 누르면 문제가 생기는지 코드 근거로 알려 주세요.
7. 모임 목록 다음 약속: 'D-2' 같은 짧은 표시는 좋아 보여요. 다만 모임이 수백 개라 목록에 표시가 너무 많아지지 않게, 가까운 약속(예: 7일 안)에만 붙이는 걸 생각 중이에요. 의견 주세요.

[2부: 커플 공간 수정본 검토. 그림 4장이 고친 화면이에요.]
고친 것: ① '하고 싶은 게임'의 반응 3개와 분류를 없애고 '같이 할 게임' 찜(하트) 하나로. 둘 다 찜한 게임이 맨 위, 거르기는 전체·둘 다·각자. ② 상대가 새로 찜하면 홈 알림과 커플 홈에 표시, 목록에 '새로'. ③ 커플 사진은 각자 한 장씩 넣으면 커플 화면 위에서 반반 합쳐짐. ④ 사진이 없을 때 다크 모드에서 커플 이름 글씨가 안 보이던 것.
관련 코드: CoupleScreen, CoupleCard, CoupleSheet, Home 의 알림 부분.
실제 커플이 몇 년 쓰고 찜이 수백 개라고 가정하고, 이번 수정의 문제와 더 좋아질 점을 중요한 순서로 최대 6개 알려 주세요. 각 항목: 어느 화면, 무엇이 문제(코드 근거), 어떻게 바꾸면 좋을지.
